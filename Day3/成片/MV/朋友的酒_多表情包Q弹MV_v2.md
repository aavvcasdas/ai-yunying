## 二、参考视频逆向工程与梗图溯源

1. **全网热梗链路**：
   李晓杰《朋友的酒》（积木鱼词曲，实测底鼓 **130.000 BPM**，拍长 `0.461538s`）→ `@活跃黑江乐`《邦友的酒(DJ版)》（夢ノ結唱 HALO 户山香澄声库翻唱）→ 衍生为抖音/B站「通透の小曲 / 所有人保持 Q 弹！」。
2. **上传参考视频（`48.62s`）逐帧拆解出的两大视觉范式**：
   - **范式 A（`0.00s–14.00s`：Windows XP 草坡巨物 + 多表情包列队群像 Q 弹）**：
     - 背景为高饱和 **Windows XP《Bliss》蓝天白云斜向绿草坡**（「看一眼整个人都通透了」的视觉锚点）；
     - **Z 轴遮挡机位**：山脊后方立有一尊**巨物主唱**（直立时 `top_y=54px` 半身傲立云端；每逢底鼓正拍压扁至 `top_y=224px`、可见高度约 `44.4%`、横向膨胀约 `148%`，下半身沉入山脊后，刚好露出一张超宽糯脸贴在草坡顶上）；
     - **山脊前景透视列队**：沿左低右高弧形山脊按近大远小排开一排小玩偶/表情包，带独立草地接触椭圆暗影，随 `130.0 BPM` 底鼓同步（或人浪）压成麻薯饼再弹起。
   - **范式 B（`15.00s–46.85s`：AI 教程工作流 + 360° 坐/站姿弹转 Q 弹）**：
     - 即梦 Seedance 2.0 全能参考公式：`图1 角色立绘 + 图2 Windows XP 蓝天草地背景 + 视频1 Q弹转圈参考片` → 剪映切分重复循环段向后复制对齐鼓点 → 配通透小曲/AI换音色；

```bash
# 0. 若本地没有《朋友的酒》音频，按需拉取到 /tmp（切勿提交 mp3 入库）
```
