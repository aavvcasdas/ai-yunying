## 一、这一稿改了什么

### 1.1 自称正名：本鱼 → 本鲸

- 旧称呼的来历不是设定，是评论**喊歪**的：Day1 的 L07 已经写明「评论区里，全在喊：大肥鱼」，L08 也写过「名字是你们起的，本鱼认了」。从 Day0 的可读评论导出里，「大肥鱼」出现约 37 次；Day1、Day2 的评论区继续这么喊。
- 结果就是人设被带偏：本来是一条鲸，被叫成了鱼，连自称都跟着变成「本鱼」。Day3 开场用一句「本鱼，不对，我了雷，鲸鱼不是鱼！是本鲸。」当场纠正，不删旧视频、不改旧成片，只在 Day3 起统一口径。
- 「我了雷」不是编的：Day2 评论里 @斩遍天下男闺蜜老豆 专门教了这套新词（「我了雷，可以用于惊讶」），账号当时回复「学会了。我雷，这段本鱼看得好认真😳」。Day3 就是这句「学会了」的正式验收。
- 「本鲸」也不是外来的：社区流传的鲸鱼娘人设卡与插件里，「本鲸 / 本鲸鱼娘 / 本小姐」本来就是标准自称（见打捞记录 `../00_运营总览/鲸鱼娘人设skill/references/sources.md`）；本项目此前用人设里的「本鱼」自嘲支线，Day3 回到「本鲸」主干，人格**没有被换成另一个人**。
- 生物学事实：鲸目属于哺乳纲，鲸不是鱼。Day3 把它当笑点，不当科普课，只在字幕小字留一句「鲸目 · 哺乳纲」。

### 1.2 新增复盘：Day2 正片和加更的数据一起念

上一稿只把数据当背景，本稿按用户要求让本鲸自己念出来，语气是自嘲，不是卖惨。

### 1.3 新增「吃得少」笑点，但不写成节食

用户给的括号内容「主人看我昨天吃的饭少，偷偷说其实是数据不好，所以吃的饭少」，本稿处理成：**本鲸昨天吃得少，不是因为要瘦、不是薄肌计划，是因为数据不好**。笑点指向数据，不指向身材；同段之后立刻用「蛋先吃一口，再游两圈。薄肌预备饭，不能光说不练」把饭量拉回正常，并在 L08 画面留字卡「今天补回来」。不出现体重、体脂率、节食挑战，也不把少吃写成值得学的事（与 `agent.md` 第 7 条一致）。

## 三、形象变更：染色即变身（本轮改动）

用户本轮明确：**从染色那一刻起，是真变成 Claude 大小姐的形象**，不是「同一条鲸鱼娘换个发色」。上一稿「同一母版只改颜色」的方案作废；保留两条不变量：**变身过程必须看得见**、**两套形象都不许拉伸变形**。

### 3.1 分段规则

| 段落 | 形象 | 画面要求 |
|---|---|---|
| L01–L02 | 原像素鲸鱼娘 | 近景正名：名牌「大肥鱼」翻面成「本鲸」；拉出后是完整房间 |
| L03 | 染色闪回 → 变身 | 染色刷从头刷下，**刷过的地方立刻是 ladyClaude**（金色螺旋卷、黑丝绒蝴蝶结、绛红长裙、折扇），刷染前线滴橙色染料；刷完一次闪白 + 星屑，变身定形 |
| L04–L15 | Claude 大小姐（ladyClaude） | 全程大小姐形象。L05 的「藏尾巴」改成下意识去藏尾巴 → 摸了个空 → 愣住 → 顺手举起折扇，台词不改 |
| L16 | 入水褪色 | 由下往上恢复：下半身先变回鲸鱼娘，上半身大小姐淡出；橙色染料丝带、气泡、水面反光；出水后只剩湿向日葵 |
| L17–L19 | 鲸鱼娘 | 蓝色本鲸抱账本返工、三笔账、口号收尾 |

### 3.2 为什么不算「偷换形象」

1. **动机在剧情里**：主人请不来 Claude 大小姐，就把本鲸染过去；变身是笑点本身，不是制作层为了省事换人。
2. **变身必须可见**：L03 用刷染前线 + 闪白 + 星屑交代；L16 用由下至上的褪色 + 染料丝带交代。禁止两帧之间无过渡硬切。
3. **比例各自守恒**：鲸鱼娘保持像素骨架与 `tailScale=1.0`；大小姐使用 `video-fx` 既有 `ladyClaude` 立绘，不横向拉伸、不缩尾巴、不给大小姐硬贴鳍耳。
4. **三处口径一致**：口播、字幕、右上角标同步——大小姐段标「Claude 大小姐（本鲸饰）」，鲸鱼娘段标「鲸鱼娘 · 本鲸」。
5. **不越界**：不宣称 Claude 本人参与制作、不写成 Anthropic 联动；旧成片不回改，Day1/Day2 的「本鱼」也不回改。

### 3.3 母版与验收

- 大小姐形象直接调用 `video-fx` 的 `ladyClaude`（金色双钻卷、黑丝绒蝴蝶结、绛红维多利亚长裙、折扇），不新画、不拼贴、不另造「橙色鲸鱼娘」。
- 鲸鱼娘继续走像素骨架；近景验收看最终 1920×1080 本体帧：睁眼时虹膜没有肤色横带，发丝、裙摆花纹、尾巴边缘清楚。
- 变身前后按同一脚底锚点与同一画面位置验收，允许的差异只来自变身特效，不允许整体缩小、位移或换头身比。
