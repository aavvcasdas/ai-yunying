## 二、Claude 大小姐：按加更电视左边的像素规格并入

### 2.1 先说清“电视左边画质”是什么

加更电视左边不是一张普通图片缩小，而是现有 video-fx 的原像素骨架：

- `pixelOld()` 以 `characterMode: 'original'` 调用 `whaleGirlBase(..., style: 'pixel')`；
- 骨架来自 `WHALE_GIRL_PIXEL_RIG`：`scale = 10`、114 色调色板、运行段（runs）逐格 `fillRect`；
- 常用站姿的原生网格约为 **80×97 格**（`wave` 骨骼并集），电视里 `leftU = 16.8`，再由 1280×720 逻辑画布以 1.5 倍输出到 1920×1080；
- 右边则是 512×512 WebP 静态姿势图走平滑缩放，所以看起来明显更“高清”。

Day3 的 Claude 必须跟左边走：**原生约 100px 高、硬 alpha、有限调色板、最近邻放大**，不能直接把一张高清立绘平滑缩进画面。

### 2.2 GitHub 现成项目结论

首选 [Silasvanceneo/claude-ojousama](https://github.com/Silasvanceneo/claude-ojousama)（本次克隆 HEAD `2c3457a`）：

- 仓库自带 47 个动作条带与 `assets/sprites/manifest.json`，每动作 4 帧横向排列；
- `tools/process_sprites.py` 的处理规格与左边非常接近：桌面场景原生目标高度 100px、BOX 下采样、alpha 硬阈值、128 色 FASTOCTREE 量化、无抖动；
- 形象为橙色长卷发、向日葵发饰与黑缎带、琥珀眼、米色开衫、白衬衫、棕色短裙，辨识点足够；
- 仓库整体为 MIT。真正并入动画素材时，须把上游 LICENSE、仓库地址和所用提交号一起归档到 `tools/day3制作/`，片尾/制作记录保留署名；
- 现有管线本来就是 Canvas + FFmpeg，不需要为了她改 Remotion。Remotion 搜到的多是通用视频技能/模板，没有现成的 Claude 大小姐角色条带；强行换渲染器只会增加字幕、时序和素材锚点风险。

已做一张规格验证图：取上游 `wave` 第 1 帧，按 97px 原生高度、114 色、硬 alpha 处理，再最近邻放大。

![Claude 大小姐左侧电视像素规格验证](Claude大小姐_左侧电视像素规格验证.png)

备选与排除：

- video-fx 里已有 `ladyClaude` 静态像素图，但实际包围盒为 53×86 格，造型是旧的双钻头卷发 + 红裙，且没有成套动作，只可作应急静态客串，不作为 Day3 首选。
- [wangxianda941030/Claude-girl](https://github.com/wangxianda941030/Claude-girl) 的白衬衫/棕裙造型更接近常见设定，但动画是高清 WebM 且美术素材为 CC BY-NC 4.0；可作服装参考，不直接并入正片。
- `Wakuwaku` 的 Claude 小姐表为 192×208 单元格，造型接近白橙裙 + 书，但仓库许可证文字明确说代码许可不覆盖宠物精灵，且原设计涉及 ZipZipPipe；权利口径未核清前只看图，不复制素材。

### 2.3 Day3 实际调用的 Claude 动作

只取少量能推动剧情的条带，不做动作目录：

| 剧情 | 上游动作 | 用法 |
|---|---|---|
| 从电视里探头、打招呼 | `peek` / `wave` | 先在电视橙色小房间右侧探头，再挥手 |
| 查票、查脸 | `magnify` / `read` / `write` | 放大镜对准 9:8 票板和旧鱼的脸，账本上记“糊不能留” |
| 看 MV 试播 | `music` / `dance` | 先跟着点头，发现歌词迟到后停住 |
| 给结论 | `error` / `sign` / `sulk` | 举牌“做得不好 · 先别发”，牌面文字由本项目代码绘制 |
| 认账返工后 | `thumbsup` / `wave` | 只给“态度通过”，不给半成品 MV 通过 |

接入时新增独立的 `drawClaudeOjousamaPixel()`：按 manifest 切帧，统一底部锚点，原生高度归一到 97 格，114 色量化，`imageSmoothingEnabled = false`。禁止借用右边 DSH 的平滑缩放路径。
