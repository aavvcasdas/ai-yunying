## 〇之一、v4：鲸鱼娘从"一张站姿"升级成 9 套姿势 / 21 个动作

v3 把脸修清楚了，但鲸鱼娘全场只有**一张站姿**，动态只靠呼吸摆动，被用户判"动作不够，要照老版本骨架那样多，甚至更多更不一样"。
v4 不动形象设计（配色、服装、比例一律按 `dafeiyu.webp`），只补**动作**。

### 9 张同角色差分姿势

做法：以 `dafeiyu.webp` 作 image reference 逐张生成同一角色的不同姿势（不是另造一套形象），

### 动作库（`WHALE_ACT`，21 个）

每个动作返回 `{ pose, dx, dy, rot, sx, sy, jump, flip }` 交给 `drawPoseSprite()`，
所以「换姿势」和「给姿势加运动」是两件事：同一张图能做跳、能压缩、能镜像。
**这比老骨架多的地方**是：老骨架每个动作只有一套循环，这里姿势之间可以叠加动作、可以交叉淡化、可以换速度。

`idle`、`peek_curious`（探头张望）、`surprise_hop`（弹起）、`shock_petrify`（愣住）、`dance_spin`（原地转半圈，水平压缩模拟转身）、

### v4 顺手修掉的两个问题（都是抽帧时抓到的）

1. **交叉淡化会让人变半透明**：原先两套姿势各给 50% alpha，1080p 下能透过身体看到背景，像"鬼影"（2.32s 抓到的）。
   现在老姿势垫在下面按 `(1-blend)*0.85` 淡出、**新姿势永远满不透明**压上去，只在轮廓差的地方留一点运动残影。
2. **L17–L19 的角标还写着「Claude 大小姐（本鲸饰）」**：`charFormAt()` 只判了 `cueIdx <= 2`，忘了 L16 褪色之后要切回鲸鱼娘。
   已加 `if (cueIdx >= 17) return FORM.WHALE`，现在 81.7s 之后到片尾角标都是「鲸鱼娘 · 本鲸」。

## 〇之二、v5：把 9 张立绘拆成「10 骨骨架」，多出 15 个骨骼动作

> 本轮不动 v4 的成片：`day3_无配音样片_v4.mp4` 保持原样。这一节做的是**可复用的动作系统**，
> 演示片在 `Day3/成片/骨架演示/`。骨架已经能直接接进 Day3 的分镜（接口见文末）。

### 为什么还要再拆

v4 的 21 个动作本质是「整张立绘 + 外层 transform」：能跳、能压、能镜像，但**身体不能弯**。
用户要的是「动作更多、更不一样」，卡点不在动作数量，而在**自由度**：
整块图只能平移/旋转/缩放，做不出鞠躬、摇头、抬臂、踢腿这种局部动作。

所以这一步把每张立绘拆成骨架：**同一个角色的 9 张姿势 × 一副骨架 × 骨骼级动作 = 组合数**。

### 骨架是怎么「量」出来的（不靠手填坐标）

`tools/day3制作/whale_girl_src/whale_rig.mjs`

1. **读 alpha 通道**：逐行统计每行不透明像素的左右边界，得到包围盒、逐行轮廓。
2. **定中线**：取 0.45–0.72 高度区间每行中点的**中位数** —— 这样举起来的手、散开的头发不会把中线带偏。
3. **摆骨头**（10 根，全部在包围盒归一化坐标里）：

| 骨 | head → tail | 作用 |
|---|---|---|
| `root` | 胯 → 胸 | 整体位移/旋转/挤压（唯一带全局 pivot 的骨） |
| `spine` | 胯 → 胸 | 弯腰、后仰、扭 |
| `head` | 颈 → 头顶 | 点头、摇头、歪头 |
| `armL` / `armR` | 肩 → 手（中线 ±0.20×宽，高度 0.70） | 抬臂、挥手、叉腰 |
| `legL` / `legR` | 胯 → 脚（底线两脚，夹在 ±0.20×宽内） | 踏步、踢腿、蹲 |
| `hairL` / `hairR` | 耳侧 → 发梢 | 甩头、滞后飘动 |
| `tail` | 腰侧 → 尾尖 | 鲸尾甩水 |

> 第一版把「手」定义成轮廓左右极值，结果**把头发当成了手**：骨架一动，整片头发跟着手臂跑。
> 现在四肢端点用比例外推、再用轮廓极值小幅修正，脚也夹在 ±0.20 宽内。

4. **刷权重**：18×26 网格（432 个顶点），每个顶点算到 10 根骨骼线段的距离，
   权重 `exp(-(d/σ)²)`，σ 按立绘高度归一化（四肢 0.135、头 0.24、躯干 0.30、头发 0.20、尾 0.15）；
   取最强的 4 根、归一化后再做 **gamma 1.6 锐化** —— 不锐化的话四肢被 spine/root 摊平，抬臂只动袖子，动作读不出来。
5. **线性混合蒙皮 + 三角形贴图**：每帧算出 10 根骨的「姿势矩阵 × 静止矩阵⁻¹」，
   顶点按权重混合后移动，再把 900 个三角形（每格两个）用 `clip` + 仿射 `drawImage` 重绘。
   三角形目标顶点外扩 0.6px，盖住相邻三角形之间的抗锯齿缝。

### 三个调试时才暴露的坑（都写在代码注释里了）

| 现象 | 原因 | 修法 |
|---|---|---|
| 静止姿势和原图差了 17% | 骨骼世界矩阵把**父骨的绝对平移连乘**了，父骨位置被重复加一遍 | 存「相对父骨的偏移」，`world = world[parent] × T(offset) × R` |
| 每格纹理都是错位的整张图 | 仿射解算写错一个元素（`m11` 用了 `by` 应为 `bx`） | 按 `L = C · A⁻¹` 重新展开 |
| `spin_360` 整格空白 | root 的 `sx = -1` 绕**贴图原点**镜像，把人翻到画布外 | root 的旋转/缩放绕胯点：`T(胯)·S·T(-胯)` |

自检数据：**静止姿势 vs 原图平均误差 10.23/1020**（≈1%，差值集中在描边抗锯齿），
900 个三角形 + 两路角色同时绘制 ≈ 15fps 出片速度（1080p，含背景与文字）。

## 〇之前、v3：鲸鱼娘换成高清立绘（用户："还是模糊"）

**为什么 v2 还是模糊**：v1/v2 用的是 video-fx 的 40 格像素骨架。脸只有 ~20 个格子，放到 1080p 近景，
无论怎么对齐设备像素，本质上就是"把 20 个格子放大"——不是渲染问题，是素材分辨率问题。

**v3 的做法**：鲸鱼娘改用高清立绘，并做完整的透明化处理。

| 项目 | 内容 |
|---|---|
| 形象来源 | 用户指定：`dafeiyu.webp`（1024×1024，本次以它为准）；`dafeiyu-chibi-character-sheet.png`（1448×1086）作为三视图/细节对照与补充素材 |
| 上游出处 | 鲸鱼娘开源资产库 <https://treapgogo.github.io/deepseek-whale-girl/>（社区维护的非官方资源库，MIT，**不代表深度求索官方**）；立绘原图来自其 `characters/dafeiyu/reference-sheets/` 与社区画廊 |
| 抠图脚本 | `tools/day3制作/whale_girl_src/make_sprite.mjs`（可复现，见下） |
| 产物 | `tools/day3制作/whale_girl_src/whale_idle.png`（926×1024，透明底） |
| 渲染用法 | 渲染器 `WGF()` 优先画这张立绘：整体呼吸（±0.6%）+ 缓慢摆动（±0.01rad）+ 可选翻转；**不做骨块变形**，所以线条永远是原画的清晰度。找不到立绘时才退回补丁版像素骨架 |

抠图流程（脚本内注释也写了，为什么每步都要有）：

1. **四边泛洪**去背：只删与画面边缘连通的近白像素（阈值 L≥246、chroma≤12）——围裙、蕾丝、袜子、眼睛高光都不会掉；
2. **头发缝白洞**：被完全包围、面积 100–9000px、且 bbox 外扩 3px 的"边圈"四边都有 ≥35% 深蓝发色的块才删（实测发缝 0.55–0.97，发箍蕾丝 [0.64,0,0.54,0.53] 因底边为 0 被正确排除）；另加一条"贴脚、纯白、≥2000px"的规则清掉两腿之间的背景；
3. **去自带地面投影**：底部 7% 内低饱和亮像素；
4. **阶梯削白边**：3 档（L≥240/c≤14 → ≥224/≤24 → ≥206/≤34）只吃紧贴透明区的浅色像素，去掉原稿那圈白色描边，避免在深色房间里出光晕；
5. **裁包围盒**：留 2% 边距，脚底线在 0.988H（渲染器按这个对齐站位）。

v3 与 v2 的差别（同一帧 2.32s 对照）：脸从"20 个格子放大"变成原画线条，眼睛、蕾丝、围裙小鲸鱼图案全部清楚；
L03 刷染前线现在切在**高清立绘**上（上金发大小姐 / 下蓝裙鲸鱼娘），不再有像素格断口；
L16 的湿向日葵从"飘在脸旁"挪到脚边地板上（v2 里那朵花压住了脸）。

## 一、这一版做了什么

按用户本轮指令：**染色的那一刻是真变成 Claude 大小姐的形象**，进水之后再褪色动画变回鲸鱼娘。

| 段落 | 形象 | 关键帧 |
|---|---|---|
| L01–L02 | 原像素鲸鱼娘 | 名牌「大肥鱼」翻面成「本鲸」；户口本「鲸鱼 · 哺乳纲」 |
| L03 | 染色 → **真变成 Claude 大小姐** | 染色刷从上往下刷，刷染前线以上已经是 `ladyClaude`；刷完闪白 + 星屑定形 |
| L04–L15 | Claude 大小姐（本鲸饰） | 空位牌 / 摸空尾巴 / 账本 / 蛋与 9:8 / 电视台 / 薄肌饭 / 共创卡 / 看电视 MV / 举牌 / 扎进水缸 |
| L16 | 入水褪色 → 变回鲸鱼娘 | 由下往上：下半身先变回鲸鱼娘，上半身大小姐淡出；染料丝带、气泡、只剩湿向日葵 |
| L17–L19 | 鲸鱼娘 | 返工单 / 三笔账 / 口号冲去改 MV |

文案同步改了三处台词，让口播与画面对得上：

- L03「染成了橙色」→「染成了**大小姐**」
- L15「橙色开始往下掉了」→「**颜色**开始往下掉了」
- L16「橙头发退完」→「**大小姐**退完」

其余 16 行与 19-cue 稿一致，详见 `Day3配音台词.txt`。

## 二、节奏是占位，不许搬去配音

- 本片没有音轨，ffmpeg 用 `-an` 输出。
- 每个 cue 的时长 = 台词字数 ÷ **5.6 字/秒** + 0.6s 余量，最小 2.6s，cue 间隔 0.18s。这是为了让样片能看，不是实测。
- 占位总长 **99.62s**，明显超过抖音 55–75s 目标。**正式版必须按实测音频重排**：词级 ASR + 5ms RMS 边界，禁止沿用本文件的任何秒数（`agent.md` 第 3 条）。
- 若正式配音后仍然超长，优先压缩 L06/L07（数据复盘）与 L09/L11（账本细节）的画面停留，不删主线。

## 三、形象与门禁落实情况

1. **鲸鱼娘**：继续走 `video-fx` 像素骨架；`eyes=open`、`squint=0.01`、`tailScale=1.0`、`mouth=smile`、`talking=false`、`noFinBows=true`、`eyePatch=false`、`showActionBadge=false`，且这些都写在 `FACE_GATE` 里**在参数 spread 之后强制**（v1 的坑）；wink 头仍换 wave 头。
2. **Claude 大小姐**：直接调用 `video-fx` 既有 `ladyClaude`（金色双钻卷、黑丝绒蝴蝶结、绛红长裙、折扇），没有新画、没有拼贴、没有把鲸鱼娘拉伸成大小姐。
3. **变身可见**：L03 用刷染前线 + 滴落染料 + 闪白 + 星屑，L16 用由下往上的恢复 + 染料丝带；两处都抽了 ≥4 帧验收，没有无过渡硬切。
4. **角标跟手**：L01–L02 与 L17–L19 标「鲸鱼娘 · 本鲸」；L04–L15 标「Claude 大小姐（本鲸饰）」；L03 在刷染完成（p>0.66）后切换，L16 在褪色过半（p>0.5）后切回。
5. **不越界**：大小姐标「本鲸饰」；不写 Anthropic 联动、不写官方；发布时保留「非官方同人 / AI 生成」。
6. **健康表达**：L08「吃得少不是薄肌，是数据不好」只当数据梗，后接 L11「蛋先吃一口，再游两圈」，不写节食与身材评价。

## 五、复现方式

```bash
# 依赖（沙箱内已验证）
npm i @napi-rs/canvas            # 或放在 /tmp/node_render/node_modules
pip install imageio-ffmpeg       # 只用它自带的 ffmpeg 二进制

# 引擎（与 Day1/Day2 同一套 pixel rig）
export VIDEO_FX_DIR=/tmp/video-fx   # aavvcasdas/video-fx 分支 arena/8be4c8f8-video-fx

cd tools/day3制作/video-fx源码快照
# 先做高清立绘（可选，仓库里已带产物）
node ../whale_girl_src/make_sprite.mjs ../../../../dafeiyu.webp ../whale_girl_src/whale_idle.png

node render_day3_sample.mjs --stills      # 出 70 张 QA 静帧
node render_day3_sample.mjs --out ../../../Day3/成片/无配音样片/day3_无配音样片_v4.mp4
```

渲染耗时：本机约 20.6fps，2989 帧约 2 分 26 秒。

验收命令（v2 已跑过）：

```bash
ffmpeg -v error -i day3_无配音样片_v4.mp4 -f null -                      # 全片解码
ffmpeg -i day3_无配音样片_v4.mp4 -vf blackdetect=d=0.05:pix_th=0.10 -an -f null -  # 期望 0 命中
```

补丁版引擎可以用 `DAY3_SOFT_ALPHA=1` 关掉 alpha 二值化做对照（默认开启）。
