## 没进仓库的（大体积成片与音频，按需从上游拉）

`mv/`（167MB 成片）、根目录各 `mv_*_whale_girl.mp4`、`whale_mv_*.mp4`、`去年夏天.mp4`、
`42868804351-1-192.mp4`、以及 `assets/*.mp3` —— 合计约 700MB，仓库里已有 Day0–Day3 的成片，
不再重复存一份。需要时按上面的分支名 clone 就能拿到，或直接跑：

```bash
git clone --depth 1 --branch arena/8be4c8f8-video-fx https://github.com/aavvcasdas/video-fx.git
```

## 怎么跑

```bash
cd video-fx
node render.mjs --style pixel --out whale_mv_pixel.mp4     # 需要 @napi-rs/canvas + ffmpeg
node render.mjs --sheets                                   # 只出角色图版
```

本机（沙箱）里 `@napi-rs/canvas` 在 `/tmp/node_render/node_modules/`，`render.mjs` 已经写了回退路径；
带音频的成片渲染需要上面列表里没入库的 mp3，只做画面测试不受影响。

> 说明：本目录是**用户自己的项目源码**，与 `Day3/` 里那条 19 cue 的运营短片是两套东西 ——
> Day3 的渲染器是 `tools/day3制作/video-fx源码快照/render_day3_sample.mjs`，它基于本项目的引擎补丁改出来，独立可跑。
