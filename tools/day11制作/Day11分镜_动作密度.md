# Day11 八镜构造（对齐 Day10 密度，开场减负）

台词是用户锁定的 25 行，一个字不改。音源是根目录 `鲸鱼找工作_克隆配音_最终版.wav`。
正式轴 `tools/day11制作/voice_alignment.json`：行边界来自实测发声段和能量谷；行内字时是发声段内插值，不是 Vosk 逐字识别（中文模型所在的 GitHub 在本环境 TLS 被断开，下不下来）。词点接触因此可能有一两百毫秒误差，不把这轴说成独立听写。

第 0 帧只留双人 + 顶部钩子横幅 + 一张岗位纸。身份铭牌 0.85 秒后入，戳章落在第 2 行「帮」，碗和立牌都不进首帧。
每镜都有一段走位，不是换个姿势继续罚站。呼吸、摆尾和镜头慢晃由通用渲染器一直带着，画面不会锁死。
