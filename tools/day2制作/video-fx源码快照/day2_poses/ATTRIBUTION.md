# Day2 姿势素材来源与许可

本目录中的 39 张 WebP 是从 GitHub 仓库
[Sutera-Diffusus/dsh-whale-musume](https://github.com/Sutera-Diffusus/dsh-whale-musume)
提交 `edd215dd8cab297084d6a45be6d69f02a800ecfc` 的 `assets/generated/`
按原文件复制的精选姿势。源仓库使用 MIT License，完整许可文本与版权声明见
同目录的 `LICENSE-DSH-WHALE-MUSUME.txt`。

这些素材只用于本项目的高清动作候选测试与后续“形象动作征集”加更，
不代表已经替换正式角色；Day2 当前版仍使用原像素鲸鱼娘。它们不包含、也不
实现源项目的桌宠、存档、养成、小游戏或宿主注入系统。候选姿势选择、
呼吸/行走/挤压拉伸、镜头内动作编排与特效代码位于上级目录的
`day2_all.js`，并由渲染器的 `original/candidate/mixed` 模式显式控制。
