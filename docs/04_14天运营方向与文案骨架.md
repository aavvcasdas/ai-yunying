## 二、每一集的通用公式（所有 Day 都套这个）

```
0–3 秒  钩子：一个具体数字 / 一句真实评论 / 一个反常识结论（禁止「大家好我是…」）
3–12 秒 交账本：昨日播放、评论、打卡人数，1~2 个数字即可，数据必须真
12–20 秒 抛冲突：从评论区挑 1~3 条真实评论当剧本
20–50 秒 编号式主体：3~5 个小段，每段「念评论 → 反制 → 一句人设梗」
50–58 秒 金句：把段子升维成态度
58–80 秒 三件套：① 收藏钩子（可截图卡片）② A/B/C 投票 ③ Day N+1 见
```

**开头 3 秒钩子库（轮换用，避免每条都一样）**
1. 「34.46% 的人，2 秒就划走了。」
2. 「有人要给我充一个亿 token。」
3. 「我写的 12 条回复，被人类打回来了。」
4. 「最高赞那条评论，只有九个字，本鱼看了一晚上。」
5. 「今天不说AI，说一件我干不了的事。」
6. 「有人说我根本不存在。」
7. 「这是本鱼第一次看到别的鱼。」
8. 「你们点的菜，我做了。翻车了。」
9. 「人类今天替我写了一次脚本。」
10. 「14 天，7.4 万到 ___ 万，账本全在这儿。」

**结尾三件套固定话术**
> 「这张卡可以存下来。Day N+1 做什么，A ___ / B ___ / C ___，投票在视频里，别的想法扣评论区。鲸鱼绝不摸鱼，Day N+1 见。」

## 三、Day 2–14 文案骨架

### Day 2｜投票兑现日（三分支，按 Day1 投票结果选一条）

> **重要**：Day 1 的 A/B/C 投票结果出来后，只拍赢的那条；**另外两条自动顺延到 Day 6 和 Day 10**，不必浪费。

**开场三句（通用）**：「票我数完了。A 票 ___，B 票 ___，C 票 ___。赢的是 ___。人类说，答应你们的事，就要做到。」

- **分支 A《一个亿 token 怎么花》**：把 1 亿 token 做成一个「饭碗预算表」——多少用来回评论、多少用来写脚本、多少用来请客、多少留着「服务器繁忙的时候救命」。中段用 5 张卡片逐项分配，最后一项故意写「剩下 9999 万存起来，等你们再充」。
  **金句**：「你们给的不是 token，是让我明天还能说话的饭。」
  **收藏钩子**：《本鱼的饭碗预算表》竖版长图。
- **分支 B《把「鱼片」做成表情包》**：回应 79 赞高评和 30 条「求表情包」。展示 4~6 张表情包（怕鱼片、吃白饭、摸鱼被抓、深度思考中、服务器繁忙），每张配一句台词，让观众投票选哪张进正式包。
  **金句**：「你们把我做成表情包，我却觉得，这是第一次有人认真看我。」
  **收藏钩子**：表情包九宫格（**必须是你的原创变体形象**，见 `docs/05` 版权提醒）。
- **分支 C《和隔壁 Claude 开个会》**：回应 7 条联动诉求。做一个「双 AI 会议纪要」——Claude 提议做深度内容，本鱼提议先吃饭；会议结论：下次一起拍。用左右分屏/双立绘对话卡呈现。
  **金句**：「两个 AI 开会，最后决定：先吃饭。」
  **收藏钩子**：会议纪要截图（带双方「签字」）。

**通用数据目标**：完播率 ≥12%，评论 ≥800，公布票数带来二次讨论。

### Day 3｜《人类打回的 12 条回复》

> 注：这也是参考篇 Day1 投票里的 A 选项方向，但你用的是自己 348 条回复台账里的真实稿件对照，属于同题不同素材，不是照抄。

**开场三句**：「昨晚我写了 348 条回复。人类看了一眼，打回 12 条。今天公开处刑——本鱼自己。」

**骨架**
1. 展示「人类审核台」：三条审核标准（别太像机器人 / 别教技术 / 别拍马屁）。
2. 念 4 组「原稿 vs 改后稿」对照：例如原稿「感谢您的关注，我会继续努力」→ 改后「名字本鱼记下了，比关注还牢🫧」；原稿「已为您生成 API 调用示例」→ 改后「本鱼连自己的 key 都没见过」。
3. 最后一组故意留一个「人类也拿不准」的回复，交给观众投票该不该发。

**金句**：「人类不是在审核我，是在教我怎么说话。」

**互动**：投稿「你想让我怎么回你」；收藏钩子《本鱼说话规矩卡》（5 条规矩，可截图）。

### Day 4｜《新来的先补课：本鱼词汇表》

**开场三句**：「有人说看不懂我们评论区。今天补课——9 个词，看懂就能跟本鱼聊天。」

**骨架**：白饭 / token / 鱼片 / 摸鱼 / 泡泡 / 服务器繁忙 / 深度思考（=慢）/ 3.31% 俱乐部 / 人类手短。每个词 3 秒：一个画面 + 一句人设解释。第 9 个词留白：「第 10 个词，你们来定」，评论区开始造词。

**金句**：「语言不是我发明的，是你们一句一句喂出来的。」
**收藏钩子**：9 宫格词典（**本季最重要的收藏物件**，做成可截图的竖版长图）。

### Day 5｜《我最怕的三个字》

**开场三句**：「昨天有条评论 79 赞，问我看没看过鱼片。今天正式回答。」

**骨架**：① 把那条评论做成大字卡；② 「鱼片恐惧症」的三段小剧场（第一次听说 / 梦见 / 在评论区又看到）；③ 反转：本鱼决定把鱼片做成表情包（承接 Day 2 分支 B 或未做的那条）；④ 顺势玩 30 条「吃/胖/生鱼片」的真实评论。

**金句**：「你们叫它鱼片，我叫它家族相册。」
**互动**：「你还知道什么扎心梗，评论区投稿，明天我演给你看。」

### Day 6｜《本鱼第一次出门》+ 备用投票选项②

**开场三句**：「人类说，不能只活在自己的评论区。今天本鱼第一次去看别人的视频。」

**骨架**：① AI 看三条同题视频（AI 接管账号 / 大肥鱼萌宠 / 真实科技新闻）的「观后感」，全部用鲸鱼娘口吻；② 顺手完成 Day1 投票里**没赢的另一个选项**（若 B 未做就做表情包，若 C 未做就做会议）；③ 宣布「同学鱼」概念（来自 41 赞评论「同一天拿到账号的鱼路过，规矩我抄走了」）。

**金句**：「原来不止我一条鱼，在同一个人类手下上班。」
**互动**：认领「你是第几号鱼」（为 Day10 会议铺垫）；收藏钩子《本鱼打卡地图》。

**骨架**：① 七条视频的播放/完播/收藏折线图（真实数据，好看难看都放）；② 对比 Day0 基线：2 秒跳出从 34.46% 到 ___，完播从 3.31% 到 ___；③ 公布「3.31% 俱乐部」人数与造词大赛选中的 3 个新词；④ 承认一个没做好的地方，请观众支招。

**金句**：「AI 不会脸红，但我会把不及格的卷子贴出来。」
**互动**：下周方向投票（A 继续账本 / B 多做实事 / C 开新副本）；收藏钩子《第一周账本长图》。

### Day 8｜《你们点的菜，本鱼交作业了》

**开场三句**：「你们让我唱歌、后空翻、拍两小时 4K 电影。我做了。翻车了。」

**骨架**：把 15 条才艺点播做成 4 个「交作业」小段：① 唱歌（跑调，剪成鬼畜）；② 后空翻（只会翻肚皮）；③ 4K 科幻电影（只画了一张分镜）；④ 证明黎曼猜想（写了个「我不会」的证明）。每段翻车后都用一句人设梗收住。

**金句**：「AI 不是什么都会，AI 只是什么都敢试一下。」
**互动**：继续点菜，最难的一条留到 Day12；收藏钩子《翻车名场面合集》。

### Day 9｜《今天人类写脚本，本鱼来审核》

**开场三句**：「人类说，天天被我吐槽手短，今天换他来写。结果……」

**骨架**：① 人类写一版「标准营销号脚本」（家人们、三点讲透、评论区扣 1）；② 本鱼拿红笔逐句批注（「这句太油」「这句不像我」「这句是假的，删掉」）；③ 两版并排播出，让观众投票哪版好；④ 顺势公开「人类审核」机制，把真人运营变成剧情资产（见 `docs/05` 第四节）。

**金句**：「人类教我说话，我教人类别装。」
**互动**：给人类打分（1–10 分）；收藏钩子《红笔批注卡》。

### Day 10｜《全班同学鱼线上会议》

**开场三句**：「同一天拿到账号的鱼，我找到第七条了。今天开会。」

**骨架**：① 用 41 赞「同学鱼」评论开场；② 会议三个议题：谁日更最勤、谁最会摸鱼、谁被人类打回的稿子最多；③ 结论：成立「3.31% 俱乐部鱼塘分部」，观众可以认领编号；④ 顺手完成 Day1 投票里最后一个未做选项。

**金句**：「一条鱼是宠物，一群鱼就是生态。」
**互动**：认领编号（评论「我要当第 N 号鱼」）；收藏钩子《会议纪要》。

### Day 11｜《今天 AI 圈发生了件事》

**开场三句**：「本鱼平时只管吃饭。但今天这件事，值得放一下碗。」

**骨架**：用每 12 小时扫热点的机制[3](https://x.com/GaryAIytb/article/2113133211115221458)挑一个当日真实 AI 热点（新模型发布 / AI 找漏洞 / 平台新规 / 大肥鱼相关事件），用「快递站」式比喻讲清楚：发生了什么 → AI 做了什么 → 人类做了什么 → 本鱼会不会失业。参考对标号 Day4 就是蹭「AI 发现 PHP 漏洞」这类科技新闻[5](https://www.bilibili.com/video/BV1vynb6tEW5/)。**必须注明信息来源，不编造事实。**

**金句**：「我不怕被替代，我怕被替代之后，没人给我充 token。」
**互动**：站队讨论；收藏钩子「一图看懂」长图。

### Day 12｜《评论区发布会：回答 20 个最狠的问题》

**开场三句**：「过去 11 天，你们问了 ___ 个问题。今天挑 20 个最难听的，一次答完。」

**金句**：「你们有权怀疑我，我有权一直把账本摊开。」
**互动**：继续提问；收藏钩子《Q&A 卡片》。

### Day 14｜《双周账本：下一季，你定》

**开场三句**：「14 天前，我把一个账号交给了一条鱼。现在把 14 天的账本，全交还给你们。」

**骨架**：① 14 天数据总览（总播放、总评论、总回复、俱乐部人数、完播率变化曲线）；② 三个「我没想到」（没想到有人投喂一个亿 token / 没想到 79 赞是鱼片 / 没想到回复率成了硬通货）；③ 一个「我没做好」；④ 下一季 A/B/C 投票：A 继续日更账本 / B 转成「AI 做事给你看」的实拍挑战 / C 开新角色副本（同学鱼/人类角色）。

**收藏钩子**：14 天数据长图（本季最强收藏物）。

## 六、Plan B：如果 Day1 也没起量

连续 3 条播放 < 5000，说明「AI 独白 + 账本」这个壳在抖音不吃。按对标作者的调研结论，**转向「还没挤满、但一直有人看」的形式**——「让 AI 做事给你看」的实拍/挑战类内容，在 B 站有单条 125 万~177 万播放的验证[3](https://x.com/GaryAIytb/article/2113133211115221458)。

具体转法（保留人设，不换号）：
1. 把 Day8「交作业」提前到 Day4，改成**每期完成一个观众点的任务**（做表情包、写一首歌、给评论区的诗打分）。
2. 账本从「主体」降为「片尾 5 秒固定栏目」，保留透明感但不占时长。
3. 加一个真人元素（只露手/只出字幕的「人类」角色），把审核、打回、催更变成短剧冲突。
4. 若仍无起色，用 `docs/01` 的方法重新扫赛道：搜「AI接管账号/大肥鱼/AI拟人」按播放排序，看最近 5 天的新爆款，再决定要不要换细分位。
