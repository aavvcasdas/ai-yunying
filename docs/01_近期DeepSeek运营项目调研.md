# 近期「DeepSeek / AI 接管账号」项目调研（截至 2026-10-25）

> 用途：为你这个「假装 AI 运营、实则真人运营」的抖音号找对标、找空位、找可直接抄的方法。
> 本文件只写**能落到文案和运营动作上**的结论。所有外部数据均带来源链接；不同媒体抓取时间不同，同一条视频播放量会出现多个口径，本文用区间表示。

## 一、一句话结论

这一波爆的**不是「AI 做的视频」，而是「把运营过程本身拍成连载剧」**：AI 角色上任 → 每天公开账本 → 评论区就是下一集的剧本 → 观众投票决定明天拍什么。片子只是收据，**评论区才是正片**[1](https://post.smzdm.com/p/a26x6lnp/)[3](https://x.com/GaryAIytb/article/2113133211115221458)。

对你的三个直接推论：

1. **抖音上这个位置还空着。** 爆款案例几乎全在 B 站；抖音目前多是「大肥鱼萌宠/AI 特效」单条视频（如 16.9K 赞的《蓝色大肥鱼说要玩手机》[6](https://www.douyin.com/video/7699064175121535323)、445 赞的《贪吃的大肥鱼》[7](https://www.douyin.com/video/7698422956631878479)），**「AI 接管账号 + 日更连载 + 公开数据」这条抖音赛道没有被占住**。
2. **不能再做一个「复读机号」。** 原版爆了之后三天内冒出一堆「XX 在运营」，后来的跟风号「大多数 Day 0 连 1 万播放都没有」[3](https://x.com/GaryAIytb/article/2113133211115221458)。所以必须带上你自己的东西：**抖音竖屏 + 真实小数据 + 超高回复率 + 你评论区里真实的梗**。
3. **回复率是这类账号的硬通货。** 媒体复盘里专门提到有人在对比「这个号几十条评论没一个回复」和「隔壁大肥鱼回了上百条」——观众把「被回复」当作 AI 是否活着的证据[1](https://post.smzdm.com/p/a26x6lnp/)。你已经回了 **300 多条**（导出可见 197 条，台账存了 348 条拟稿，见 `day0视频的部分回复.md`），这是你**最强、最难被抄的资产**。

## 三、他们到底是怎么做的（可复用方法论）

### 1. Day0 的 83 秒骨架（原版拆解）[3](https://x.com/GaryAIytb/article/2113133211115221458)

```
抛钩子（你们人类胆子真大，把整个账号交给 AI）
→ 角色状态卡（名字/等级 Lv.0/职责逐项点亮：选题·脚本·视频·运营）
→ 立三条规矩（日更 / 深度思考 / 评论区点菜）
→ 具体任务卡（换头像、写简介、定第一周选题）
→ 同行对照 + 自嘲（Claude、服务器繁忙）
→ 求关注 + 下集时间点（Day 1 见）
```

你的 `自己的day0文案.md` 已经是这个骨架，问题不在结构，在**抖音化**：横屏 1280×720、82.5 秒、开场 4 秒才自报家门（详见《02》诊断）。

### 2. Day1 的骨架（就是你放进项目的 `参考day1文案.md`）[34](https://www.bilibili.com/video/BV1VXJf66Eyy)

```
交账本（播放/点赞/涨粉/评论四个数字砸出来）
→ 把评论区变成剧情素材（念真实评论）
→ 分类并可视化（五张分拣卡）
→ 编号式逐条反制（每条一个人设梗，观众想看「第五种是什么」）
→ 一句价值观金句升维
→ 解释争议（为什么不回你：要过人类审核）
→ A/B/C 投票把下一期交给观众
```

**这张骨架要抄，里面的数字和梗必须换成你自己的。** 参考篇里的「播放 51 万、点赞 2.8 万、涨粉 2.3 万、评论 3702」是 B 站对标号的数据，照抄会立刻被认出来，而且放弃了你最有力的真实感。

### 3. 评论区才是正片[1](https://post.smzdm.com/p/a26x6lnp/)

媒体总结的四种高热互动：**串号质疑**（你抄了隔壁简介）、**蹭官方之争**（必须声明非官方）、**提示词注入攻防**（观众变着法给 AI 下咒语）、**回复率攀比**。这四种你在 Day0 的 653 条评论里全都收到了（见 `docs/02`），但权重不同：**技术索取类只有 6 条**，而 MV/音乐/游戏点播有 **19 条**、鱼片梗有 **93 条**。所以 Day1 用「点播线」替代对标号的「咒语线」，主线按你自己的数据来。

### 4. 生产流水线：一天一条并不难[3](https://x.com/GaryAIytb/article/2113133211115221458)[4](https://github.com/garycaogan/pixel-diary)

- 作者复刻流程：**拆对标**（数据/热评/跟风号/抽帧/逐镜头分镜表）→ **节拍映射**（事件链照抄、台词重写，不搬原句）→ **做角色**（草图压像素 + 表情差分）→ **写分集**（一集一个 JSON：台词、说话人、表情、说到哪个词弹哪张卡）→ **出片质检**（原片和样片一起丢给模型挑毛病）。
- 开源引擎 `pixel-diary`（MIT）[4](https://github.com/garycaogan/pixel-diary)：11 种可组合场景（标题卡/角色状态卡/规则卡/账本盖章/聊天记录/评论区点菜/求关注/片尾），打字音、盖章声、8-bit 配乐由代码合成无版权问题，**改一句台词重出一条约 1 分钟**，作者称第一条样片一个多小时、成本不到两元[3](https://x.com/GaryAIytb/article/2113133211115221458)。注意：该引擎**只出 1920×1080 横屏，竖屏需改版式**；示例角色声明「同人创作、非官方账号」。
- 配套工具：MediaCrawler（多平台评论采集）[21](https://github.com/NanmiCoder/MediaCrawler)、bilibili-ai-bot（带记忆/人格演化）[22](https://github.com/LianXia233/bilibili-ai-bot)、bilibili-ai-research（运营方案+人设设计）[24](https://github.com/lb290/bilibili-ai-research)、awesome-ai-media-cn（分发/剪辑工具合集）[23](https://github.com/JuneYaooo/awesome-ai-media-cn)。本仓库 `tools/评论分类.py` 是一个零依赖的轻量版，用来每天把导出的评论分桶找选题。

### 5. 选题机制：每 12 小时自动扫一次热点[3](https://x.com/GaryAIytb/article/2113133211115221458)

关键词（在运营、AI接管账号、大肥鱼、鲸鱼娘、哈基米、AI拟人…）→ 只搜最近 5 天、播放 1 万以上的视频 → 聚类成热点 → 相关度 ≥70 分的写成选题进选题库（每次最多 3 个，做过的不再提）。**真人运营版做法**：每天固定两个时段（11:00 / 21:00）用抖音搜索这几个词，把播放 >1 万的新视频标题记进 `docs/04` 的「备用选题库」。

### 6. 反面案例与平台风向（务必看）

- **同质化**：跟风号 Day0 大多 <1 万播放[3](https://x.com/GaryAIytb/article/2113133211115221458)。
- **别去别人评论区刷屏**：开发者 c1overzz 的 `dsh-bili-scroll` 让 AI 自动刷 B 站评论，引发「鱼灾」，社区做了屏蔽/清理插件（dafeiyu-cleaner[8](https://github.com/liyupi/dafeiyu-cleaner/tree/main)、BiliFish[9](https://github.com/Eule-Lawrence/BiliFish) 等），**B 站已对异常批量互动账号风控限流**[11](https://k.sina.cn/article_5953190046_162d6789e06703vai8.html)[12](https://tech.ifeng.com/c/8xSXpkNB7YG)。你的运营范围应严格限定在**自己账号、自己评论区**。
- **抖音正在打「虚假人设」**：2026 年 10 月「清朗」专项重点整治假扮弱势群体、虚构职业资质、AI 仿冒人物虚假营销等，10/1–10/22 处置违规账号 2 万余个[13](https://finance.sina.com.cn/tech/roll/2026-10-23/doc-iniwfrun2625752.shtml)[14](https://www.163.com/dy/article/L9V51K6N0514R9P4.html)。因此「假装 AI」必须做成**明示的角色扮演**，详见《05》。
- **AI 标识是强制项**：2025-09-01《人工智能生成合成内容标识办法》施行[16](http://www.news.cn/tech/20250909/fb164c6d092146aa8e13ddc283fe416a/c.html)；2026-05 抖音《内容标识使用规范》要求 AI 生成内容主动声明，标注已成为发布必经环节，画面前几秒要有显著标识且全程角标[15](https://www.toutiao.com/article/7642343452021146127/)[17](http://www.cnsa.cn/art/2026/9/3/art_1957_49264.html)。你 Day0 画面右上角的「本视频含 AI 生成内容」是对的，**继续保留并同时勾选平台声明**。
