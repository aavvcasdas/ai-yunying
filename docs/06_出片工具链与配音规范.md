## 二、统一配音规格（全项目强制）

| 项 | 规定 |
|---|---|
| 引擎 | 微软 **Edge TTS**（Python 包 `edge-tts`） |
| 音色 | **`zh-CN-XiaoyiNeural`（晓伊）** |
| 语言 | zh-CN |
| rate | **不加偏移**：不传 `--rate`（等价 `+0%`） |
| pitch | **不加偏移**：不传 `--pitch`（等价 `+0Hz`） |
| volume | 不加偏移（不传 `--volume`） |
| 适用 | Day0 重配音、Day1–Day14 全部口播、评论区语音/动态配音、video-fx 引擎里任何新旁白轨 |

配置落在 `config/tts.json`；一键生成脚本 `tools/生成配音.py` 会**校验音色与零偏移**，并且**永远只向 Edge TTS 传 `text` 和 `voice` 两个参数**——这是「rate/pitch 不加偏移」最保险的实现方式（不是传 `+0%`，而是根本不传）。

### 用法

```bash
pip install edge-tts

# 查看当前规范（不需要联网）
python3 tools/生成配音.py --print-config

# Day1 主版（约 80 秒）
python3 tools/生成配音.py --text-file day1_配音稿.txt --output audio/day1.mp3

# Day1 极速版（约 48 秒，用于 A/B 测钩子）
python3 tools/生成配音.py --text-file day1_配音稿_极速版.txt --output audio/day1_fast.mp3

# 单句试听
python3 tools/生成配音.py --text "停。34.46% 的人，2 秒就划走了。" --output audio/hook.mp3
```

等价的原生 CLI（同样**不要**带 `--rate` / `--pitch`）：

```bash
edge-tts --voice zh-CN-XiaoyiNeural --file day1_配音稿.txt --write-media audio/day1.mp3
```

Python API 等价写法：

```python
import edge_tts
comm = edge_tts.Communicate(text, "zh-CN-XiaoyiNeural")  # 不传 rate / pitch
await comm.save("audio/day1.mp3")
```

> Edge TTS 需要访问微软服务，请在能联网的本机执行；沙箱内只允许访问 GitHub/PyPI，因此本轮**没有实际合成音频**，只把规范与脚本准备好。

### 与出片流程的衔接

1. 用 `tools/生成配音.py` 把 `day1_配音稿.txt` 合成 `audio/day1.mp3`。
2. 用 ffmpeg 提取该 mp3 的语音包络，替换 `tools/video-fx/assets/audio_envelope.js` 里的 `voice` 数组（或直接重跑包络提取脚本），让鲸鱼娘口型对上晓伊的声音。
3. 在 `tools/video-fx/src/ch/` 下新增 `day01_*.js` 分镜（复用 Day0 四幕的组件），把 `docs/03` 的账本卡、五封来信卡、会员证卡、投票卡做成卡片队列。
4. `render.mjs` 出 9:16 竖屏 1080×1920（Day0 是 1280×720 横屏，竖屏版式必须重排，见 `docs/02`）。
5. 发布前按 `docs/05` 的预检清单勾选「AI 生成 / 虚构演绎」。
