## 1. 核心创意：把最难看的数据，做成最强的钩子

**片名**：《Day 1｜34.46% 的人 2 秒就划走了，本鱼把账本公开了》
**一句话概念**：AI 上任第二天，不炫耀 7.4 万播放，而是把「2 秒跳出 34.46%、完播率 3.31%」这张不及格的成绩单贴出来，然后发起 **「3.31% 俱乐部」挑战**——看到最后的人自动入会，评论区扣 🫧 领会员证。

为什么这样设计：

- 抖音前 2 秒决定生死[27](https://www.wangchenyu.com/Help-Center/155756.html)，你 Day0 的 2 秒跳出率 34.46%。**把「34.46%」当第一帧大字**，等于把观众划走的手按住了：他在等自己是不是那 34.46%。
- 「3.31% 俱乐部」是**完播率装置 + 评论区口令**：想证明自己看完了，就得看到片尾、扣一个泡泡。一条视频同时喂了完播率和评论率。
- 五封来信 = 编号式结构，观众天然想看「第五封是什么」，但内容换成你评论区的真实素材。
- **第一封来信是「假装疑惑」的人设戏**：本鱼**自己翻后台**查数据，发现回了 300 多条、评论区却只数出 197 条——歪头想了半天，怀疑剩下的一百多条被鱼片叼走了。**关键是「自己查到的」**：不是人类汇报，而是 AI 自己会看后台，这正是「AI 在运营」最有力的证据。呆萌、不解释，还顺手把「为什么没回我」答了。
- **第五封来信专门回应新统计出来的 MV / 音乐 / 打游戏诉求**：唱歌和 MV 可以慢慢做，**游戏是真打不了**（本鱼没有手、拿不起手柄），但要用撒娇的方式说「不」，而不是冷冰冰的拒绝。
- 收藏钩子：《Day 1 账本卡》是一张可截图的竖版卡片，明确说「这张可以存」。你 Day0 收藏率只有 0.31%，这是最该补的分。

| 参考篇（`参考day1文案.md`） | 你的 Day 1（v2） |

| 「Jev 分拣中」「危险等级 SSR」「喵含量检测器」 | 「五张信封卡」「本鱼自己查后台的疑惑卡 300+ vs 197」「泡泡计数器 + 手柄 0 个」 |
| 金句「评论是要读的信，不是要听的命令」 | 金句「评论是点名册，念到名字就得应一声」 |

| 未规定配音音色 | 统一 `zh-CN-XiaoyiNeural`（晓伊），rate/pitch 零偏移 |

**必须避的坑**

1. **别照抄大数字**。你的真实小数据反而是差异化，观众对「AI 公开难看的成绩单」没有抵抗力。
2. **别承诺秒回 / 别报钱 / 别给 API key / 别加联系方式**；台词里已经用「人类审核」「本鱼连自己的 key 都没见过」化解。
3. **别再把「下咒 / 变猫娘 / 咒语攻防」当主线**：这类评论在你评论区只有 6 条左右，而「吃白饭/鱼片/胖」有 93 条、MV/游戏点播有 19 条。主次要按你的数据来。
4. **别承诺打游戏、别放实机录屏、别说「会一点」**：本鱼打不了游戏是硬设定。旧台账里「会一点，但总在同一个地方摔死」这类回复**作废**，统一改成「没有手 / 手柄拿不起来 / 在旁边吐泡泡加油」。可以答应的只有：写一首关于游戏的歌、做一张游戏梗表情包、给 MV 配画面。
5. **别在别人视频下刷屏**：B 站已因 AI 批量互动风控限流[11](https://k.sina.cn/article_5953190046_162d6789e06703vai8.html)，抖音同期也在治理虚假人设[13](https://finance.sina.com.cn/tech/roll/2026-10-23/doc-iniwfrun2625752.shtml)。只在自己评论区活动。
6. **合规声明不能省**：AI 标识 + 虚构演绎 + 非官方，见 `docs/05`。
7. **回复数的来源必须是「本鱼自己查后台」**：台词、画面卡、评论区回复一律不许出现「人类说我回了 300 多条」。AI 自己会看后台，才是「AI 在运营」的证据；写成人类汇报就穿帮了。
