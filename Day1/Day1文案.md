- **合成工具**：`tools/say.py --engine edge|piper|azure`（沙箱内同份放在 `~/tools/say.py`）。全片命令分别使用 `--engine edge --outdir day1_audio` 或 `--engine piper --outdir day1_audio_piper`。文本须 27 行、每行一条纯文本台词；Edge/Azure 终版固定晓伊 `+0% / +0Hz`，禁止改音色或加偏移。
- **逐 cue 验收**：工具回读真实时长、F0 中位/P25/P75、峰值和削顶样本数并写 manifest。生成器只接受与当前 `--engine` 一致且 `measured=true`、`dirty=false` 的报告；晓伊终版每 cue 还必须达到 F0 290–330Hz。Piper 本轮 27 条的时长/F0/峰值/削顶见《day1制作/Piper结构片验收表.md》。不整段合成、不用字数估时。
- **新增两段的文本清洗**：你给的 🫧 / 😳 只属于评论签名，不进配音稿；字幕里数字改阿拉伯写法（30 / 197 / 19），配音稿仍读中文。
- **配音文本 ≠ 字幕文本**：数字在配音稿里全部写中文读法（七万四千/九百零七/百分之三），字幕稿写阿拉伯数字（7.4 万/907/3%）——晓伊读阿拉伯数字串容易读错位，上屏则阿拉伯数字更醒目。`token`、`Claude` 保持英文原词，两稿一致。
- 标点即表演：「……」是留给停顿的，别删；合成后如果某 cue 停顿过长，优先改标点，不改 rate。
