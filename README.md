# ai-yunying · 鲸鱼娘「AI 运营」项目

真人单人运营、对外呈现为 AI 运营的短视频账号项目。本仓库只保存本账号自己的文案、数据、评论、制作归档与成片；所有数字、票数和评论归属都必须能回溯到项目文件或用户明确提供的数据，不能编造。

## 制作门禁

1. **不按字数估时**：每个 cue 的时长、字幕与镜头卡点必须来自实测音频。
2. **终版音色**：Microsoft `zh-CN-XiaoyiNeural`（晓伊），rate `+0%`、pitch `+0Hz`；逐 cue 合成并回读时长、F0、峰值与削顶。
3. **Piper 只作占位**：`zh_CN-huayan-medium` 只能用于离线结构片，必须明确标注非晓伊，不能冒充终版。
4. **Day2 开场**：禁止复用前两集红幕拉开和无声标题卡；生成时 `TITLE_LEN=0`，L01 第一帧直接进入桌面开票。详见 `Day2/Day2文案.md` 的冷开场门禁。
5. **画面不变量**：主角像素骨架、原生 1920×1080、clean 背景/文字、`tailScale=1.0`，wink 使用 heart 后发。
6. **标识**：发布时保留非官方同人/AI 生成标识，不使用“官方艺名”等表述。

## 新增文件放哪里

- 每一集的文案、台词、原始数据、评论与成片放进对应 `DayN/` 文件夹，不再散落仓库根目录。
- 新成片先进入对应集数的 `成片/当前版/`；被替代的版本移入 `成片/历史版/` 并在制作记录注明禁止误发原因。
- 外部样片只放 `参考资料/`，跨集规划只放 `00_运营总览/`。
- 渲染中间帧、缓存和日志默认不入库，见 `.gitignore`；需要留档的关键验收帧须在制作记录中说明后单独提交。
