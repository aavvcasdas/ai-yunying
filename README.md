# ai-yunying · 鲸鱼娘「AI 运营」项目

真人单人运营、对外呈现为 AI 运营的短视频账号项目。本仓库只保存本账号自己的文案、数据、评论、制作归档与成片；所有数字、票数和评论归属都必须能回溯到项目文件或用户明确提供的数据，不能编造。

仓库级生产规范见根目录 [`agent.md`](agent.md)。其中文首的 ai-yunying 覆盖规则优先级最高，下方保留的 video-fx 原文只用于理解角色骨架、动作系统和渲染架构。

## 制作门禁

1. **不按字数估时**：每个 cue 的时长、字幕与镜头卡点必须来自实测音频；连续 WAV 先做词级 ASR，再用波形 RMS 修正边界。
2. **声音口径如实记录**：Microsoft `zh-CN-XiaoyiNeural`（晓伊）是既定终版音色目标，但只有带可验证来源、且逐 cue 实测通过门禁的音频才能称晓伊。Day1 与 Day2 的用户 WAV 都没有可验证引擎元数据，不能事后冒充晓伊。
3. **Piper 只作占位**：`zh_CN-huayan-medium` 只能用于离线结构片，必须明确标注非晓伊，不能冒充终版。
4. **Day2 开场**：禁止复用前两集红幕和无声标题卡；`TITLE_LEN=0`，L01 第一帧直接进入桌面开票，“没手”只在 L03 末尾落点。
5. **画面不变量**：主角像素骨架、原生 1920×1080、clean 背景/文字、`tailScale=1.0`，wink 使用 heart 后发。
6. **标识**：发布时保留非官方同人/AI 生成标识，不使用“官方艺名”等表述。
7. **自称与称呼口径**：Day3 起主角默认自称「本鲸」，傲娇或伪装亮相可称「本小姐」；「本鱼」只留作自嘲、引述 Day1/Day2 旧集；「大肥鱼」是住户喊歪的称呼，只用在被引述与傲娇反弹里，不能当自称。改稿先过 `00_运营总览/鲸鱼娘人设skill/SKILL.md` 第 7 节的 OOC 清单。
