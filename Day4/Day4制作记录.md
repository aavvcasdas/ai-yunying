## 二、老版像素骨架怎么变清晰的（这是本轮技术核心）

Day3 v2 被判「糊」，根因不是分辨率不够，而是**像素边界落在半像素上**：

1. 主画布 `setTransform(1.5)`（720p 逻辑 → 1080p 输出），再叠镜头 zoom（1.02～1.28），
   于是每个格子 = `u × 1.5 × zoom` = 非整数像素；
2. canvas 抗锯齿把每个格子边缘抹成半透明灰边，旋转/摆动（headBob、hairSway）还会再糊一层。

`blitChar()` 的做法（默认开启，`--soft` 关闭做对照）：

| 步骤 | 实现 | 效果 |
|---|---|---|
| ① 设备分辨率离屏层 | 每格宽度取整 `cellDev = max(2, round(u×s/10))`，`uDev = cellDev×10` | 格子边缘永远落在整数设备像素 |
| ② alpha 二值化 | `d[i] = d[i] >= 110 ? 255 : 0` | 砍掉旋转产生的半透明边，不再有灰晕 |
| ③ 最近邻贴回 | `imageSmoothingEnabled=false`，位置四舍五入 | 正方形硬边，放大也不出灰线 |
| ④ 眼睛白线门禁 | `eyes='open'`、`squint=0.01`、`noFinBows`、`eyePatch=false` + `engine_patches.mjs` 五项补丁 | 沿用 `agent.md` 第 11 条 |

**证据**：`Day4/成片/QA/鲸鱼娘清晰度对比_软vs硬.png` 是同一帧（t=1.17s）同一裁切的左右对比，
左＝旧做法、右＝现在；两张都是渲染器真实输出，不是手绘。

> 注意：这套做法让老骨架「干净」，但**不会让它变成高清立绘**——
> 原版骨架每格就是 1 像素的色块，格子大时看得出方块（这正是"老版像素"的味道）。
> 如果用户要的是「保留老版动作、但要高清线条」，那是 Day3 的立绘路线，不是这条。

## 四、怎么重跑

依赖（沙箱里已装好，不进程仓库）：

```bash
cd /tmp/node_render && npm i @napi-rs/canvas @ffmpeg-installer/ffmpeg
```

```bash
# 只看帧（默认开清晰化）
node tools/day4制作/render_day4.mjs --stills
# 出「关清晰化」对照帧（文件名带 _soft）
node tools/day4制作/render_day4.mjs --stills --soft
# 并排对比图
node tools/day4制作/make_clarity_compare.mjs 1.17
# 出片（无音轨样片）
node tools/day4制作/render_day4.mjs --out Day4/成片/无配音样片/day4_无配音样片_v1.mp4
# 有实测 cue 与配音之后
node tools/day4制作/render_day4.mjs --cues Day4/day4_voice_alignment.json --audio Day4/配音.wav --out Day4/成片/当前版/day4.mp4
```

其他开关：`--no-tv`（C02 不画电视，做对照）、`--times 3,8,14 --tag chk`（指定秒数出帧）、
`VIDEO_FX_DIR` 指定引擎路径（默认仓库内 `video-fx/`）、`FFMPEG_PATH` 指定 ffmpeg。
