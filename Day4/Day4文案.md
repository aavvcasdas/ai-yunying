## 二、0–3 秒钩子（三版，主片用 A · 超级呆萌）

> v2 核心改动：旧版 A 是「两条视频涨了 6 个粉」的直白报告，**不够呆萌、留不住人**。
> 现在第一句改成奶凶 + 天真反问 + 悬念：先让观众愣一下「谁要被换掉？为什么？」。

| 版 | 0–1.5s 人声（≤10 字） | 第一帧大字 | 第一帧画面 |
|---|---|---|---|
| **A（主片）** | 「诶？本鲸被换掉啦？」 | `诶？被换掉啦？` | 本鲸歪头、呆毛弹一下、头顶大问号；背景里 Q 版大小姐的茶杯已经摆上本鲸的工位（异常信号） |
| B | 「主人好坏……把本鲸的 MV 送人了。」 | `MV 被送人了？` | 本鲸趴桌，一张「MV→大小姐」的箭头贴纸飞过 |
| C | 「呜……本鲸做的 MV，主人看了十版都摇头。」 | `十版都被摇头` | 一摞 v1…v10 返工单糊到本鲸脸上 |

三版共用：第 0 帧就是**动作中段 + 大字 + 人声**，无淡入/无标题卡/无站姿；
第一句是完整短话（≤10 字）、不带从句、不带黑话；大字占屏宽 60%+、描边、静音可读。
`HOOK_TEXT` 放渲染器顶部一行换一版。

**为什么 A 最留人**（来自数字人口播/3 秒留人调研）：
1. 语气词「诶？」先给呆萌反应，不是播报；
2. 「被换掉」制造**预期违背**——观众预期是「今天报账」，结果一上来是「要被换掉」；
3. 疑问句天然留钩子，逼观众等下一句解释。

中央网信办 9-30 明确「**声明 AI 生成不能为数字人卖惨带货免责**」。

所以本片必须这样写（v2 已按此执行，且呆萌化后**更不像卖惨**）：

| 风险点 | 本片做法 |
|---|---|
| 装可怜骗同情 | 全部是**真数据自嘲**，语气是奶凶嘴硬（「才怪！本鲸才不伤心呢」），不是哭诉求救 |

## 十二、v2 用到的「呆萌快节奏」硬规则（写文案必看）

> 完整版见 `agent.md` 第 16 条、`SKILL.md` 第 4/10 节、`references/cute_fast_script.md`。
> 这里只列 Day4 用到的落地口径。

| 规则 | Day4 怎么做 |
|---|---|
| **超级呆萌开头** | 第一句「诶？本鲸被换掉啦？」——9 字、奶凶反问、预期违背、疑问句留钩子 |
| **短句** | 每句 ≤15 字为主，硬上限 25 字；Day4 全片无 >18 字长句 |
| **快节奏** | 语速 4.3 字/秒，约 70 秒 / 300 字；每 5–7 秒一个画面/情绪点 |
| **少废话** | 删掉旧版「社区里都算过：DeepSeek 这边一百万 token 两块……差了八十多倍」这类长算账；数字只做画面卡，口播最多一句短反差（「它强归它强，本鲸便宜呀」） |
| **呆萌口癖** | 诶？/呜/嘿嘿/我了雷/呀/呢/哦/呗/委屈——覆盖率 >40%，但不每句都用 |
| **无 AI 味** | 禁「首先/其次/综上/值得注意的是/社区里都算过」等解释腔 |
| **承诺链** | 小目标 + 月度目标 + 明天账本卡，结尾只留「评论区说句话就行」一个动作 |
| **事实/合规** | 数字全可回溯、「报数不卖惨」、AI 生成声明、零打赏引导（第七、八节） |
| **loop 门禁** | `呆萌体检.py`（怎么说）+ `开场体检.py`（说什么/第几秒），两道都过才配音 |
