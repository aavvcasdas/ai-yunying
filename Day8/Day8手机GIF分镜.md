# Day8 手机 GIF 无配音样片

## 本轮范围

采用上轮审核稿，不改口播文字。把上传的 GIF 按台词放进代码绘制的手机屏幕中。原素材不改动。

- 样片约152秒，1920×1080、30fps，无任何音轨。
- 字幕时间是结构临时排布，不是实测配音；配音到位后重新对齐。
- 手机内为动态GIF，不是首帧贴图；保留原有逐帧时长循环。
- 写码、摸鱼、装忙、被抓、结算、投票、放假票各有对应台词段。
- 老大的左右指向及叉腰素材用于探头、查岗、提问镜头；在派生缓存中去除连通黑背景，不改原GIF。
- 素材顶部HUD与底部计时、指标区域用手机内的标题及场景提示替换。原始玩法画面保留。
- 投票按钮是无结果的玩法演示，不伪造观众投票实录。
- “还有bug”不编造新的故障片段：手机展示初样，外侧角色检查代码。
- 末句结束后0.2秒停片，无片尾卡。

## 复现

node tools/day8制作/render_day8.mjs --cues tools/day8制作/样片归档/sample_cues.json --subs tools/day8制作/样片归档/sample_subtitles.json --out Day8/成片/历史样片/Day8_手机GIF_无配音样片.mp4
