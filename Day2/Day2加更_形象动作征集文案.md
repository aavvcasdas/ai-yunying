## 一、这条加更到底解决什么

观众反馈集中在两件事：

1. 原形象在成片里显得糊，头发、眼睛和衣服细节看不清；
2. 个别无语表情的眼睛被盖得发白。

上一轮测试直接把 Day2 主角整体换成高清姿势图，虽然解决了清晰度，却把“增加动作、丰富形象”做成了“换了一个人”。这条加更要把决定权还给观众，但又不能只问一句空泛的“你们觉得哪个好”。

### 搜索后采用的四个原则

- **前三秒先给冲突和证据**：短视频开头应让画面、屏幕字和声音同时说明发生了什么，前后对比也应尽量前置，不要先报标题再慢慢铺垫。[1](https://juejin.cn/post/7697087660391432202)
- **投票先低门槛，再开放补充**：结尾让观众扣数字或选 A/B，比只问“大家觉得呢”更容易得到可统计的答案；有具体改法的人再写长评。[7](https://www.hailuoshe.com/blog/video-ending-call-to-action)
- **虚拟角色适合共创，但不能把共创做成突然换人**：虚拟偶像的形象和设定较灵活，粉丝可以参加投票与共创；正因如此，更要先把“原版仍在、候选只是试穿”说清楚。[1](http://www.news.cn/globe/20250709/c93d27769ca94c0ba1f0d763dc307b7e/c.html)
- **改版必须保留识别锚点**：角色设计首先要有辨识度，标志性的轮廓、配色、发型、服装结构和道具一变，观众就可能把她认成另一个角色。[2](https://www.xiuzhan365.com/blog/4564.html) [3](https://www.elser.ai/zh/blog/anime-ai-generator-guide-consistent-characters-scenes)

所以本集不问“旧的淘汰还是新的上位”，而问：

> **脸和轮廓还是原来的本鱼，只给她补清晰度、补动作、补一点服装细节，可以吗？**

后半段顺手把评论区另一笔旧账讲清：Day0 已经有人问“每个人都回你回的过来吗”，本鱼当时的回复就是“一天两百条就顶了”。这次用 Day1 导出的可读记录把原因摊开——226 条里住户写 112 条、本鱼自己回了 114 条，评论区几乎一半是本鱼在说话——再借电视抽卡回复四条和本集主题直接相关的真评论：4K 电影、表情包、后空翻和衣服。抽评不是另开一桌，而是把“为什么要换台投票”落回到观众真的说过的话上。

## 二、先钉死不能改没的“户口本信息”

无论最后选哪种方案，下面五项先保留：

| 识别锚点 | 处理原则 |
|---|---|
| 蓝色长发 + 头顶呆毛 | 发色、长发轮廓和呆毛不改成另一种发型 |
| 蓝色眼睛 | 可以画清虹膜和高光，不能再出现整块发白 |
| 女仆头饰 + 鲸鱼围裙 | 可以补蕾丝和纹样，不换成完全不同的制服 |
| 大蓝尾巴 | 保持 `tailScale=1.0` 的存在感，不为了构图悄悄缩小 |
| 白饭碗 | 继续做本鱼的随身证据，不因换动作就消失 |

候选款在画面里可以简称 **“新版试穿”**，正式标签仍写 **“动作试穿员 / 高清候选款”**；不叫“正式新版鲸鱼娘”，更不能在投票前说“以后就长这样”。电视机段默认是 **屏内播老版、屏外展示新版候选、原版真身拿着遥控器在旁主持**，这样既能把新版动作放成主画面，也不会把原版演成已经被关进电视里下岗。

## 五、背景统一规则：电视机进场后，换台就是换场景

这条加更的场景按一条参观路线连续推进；B10 以后不再另搭一个普通“投票厅”，而是让电视机君成为后半场的中心道具——屏内负责证据和数字，屏外负责全身大小的动作展示：

```text
深海评论瀑布
  → 脸部检修台
  → 深夜动作快递站
  → Claude 大小姐工作台
  → 户口本展示墙
  → 双人试衣展柜
  → 动作练习场
  → 深海电视放映厅（CH00 对比台）
  → CH01 老版修清 / CH02 新版试穿 / CH03 借动作衣服 / CH04 住户点单
  → 评论回放与数据台
  → 电视抽卡口
  → 四频道电视尾卡
```

统一约束：

1. **一句话至少有一个对应物**：说评论就先看到评论卡，说眼睛就看到放大镜和眼睛，说动作大全就看到箱子和编号卡，说老版就在电视里重播，说新版就让候选站在电视外同动作对照，说投票就看到遥控器的数字键。
2. **电视机的职责只管“播证据”**：老版片段、频道选项、评论原文和 226 / 112 / 114 的计数都进屏幕；真正需要看清身体比例和动作幅度的展示放在电视外，避免新版被小屏幕压得又糊回去。
3. **每两到三句换一个功能区**，靠推门、拉帘、传送带、换台雪花和镜头横移衔接。雪花只在切台、串台两个梗点短闪，不拿噪点当全片滤镜。
4. **原版永远在主持位，电视机不是新主角**：原版读评论、开箱、介绍、模仿、按遥控器、公布评论上限并抽卡；电视机君只有轮子、天线和机械臂的小动作，不配第二把声音。候选款只在展台、练习场和电视外做演示。
5. **每个 cue 最多一个主梗**：遥控器没电、频道锁、针线包被打叉、计算器冒烟、对讲机串台、衣服像被子都只服务当句台词；笑点不能挡住选项数字和评论原文。B18 四连抽是唯一允许快切的段落，但每张卡也必须停够读完正文的一拍。
6. **颜色跟着频道走**：评论和检修段偏冷蓝，开箱段加暖黄工作灯，动作段用青绿和粉色分区；CH01 用像素蓝，CH02 用清亮的浅青，CH03 用衣料粉，CH04 和评论数据台回到户口本金色。深蓝只做海水底色，不再让整片只剩一面墙和一条棕色地板。
7. **背景文字只留关键词**：每屏最多一个大词，如“太糊啦”“动作大全”“原版不下岗”“CH00 对比台”“评论区选台”“本鱼自己占了一半”；频道说明和抽评正文属于证据文字，可以保留，但不把制作说明贴满墙。
8. **同一组道具贯穿全片**：户口本从 B05 出现、B09 被尾巴扇动、B14 盖“先保留”章、B19 回到原版怀里；白饭碗先做双人比例参照，B18 再被“被子衣服”罩住；遥控器 B11 第一次没电、B13 交给评论区、B19 伸向观众。道具连续，观众不会觉得电视机是后半段突然空降的另一部片。

## 七、下一步制作门禁

1. **这份文案先审，不直接配音**：先确认 B01–B19 的电视机版本是否保留，尤其是 B18 四连抽的节奏；确认后再逐 cue 生成最终配音，并继续按“实测时长定版式”的门禁执行，禁止按字数估时。
2. **先做静帧，不整片盲渲**：优先做 B01、B02、B05、B06、B08、B10、B13、B16、B18、B19 十张样帧，确认电视机尺寸不吞人物、屏内老版可辨认、屏外新版够清楚、遥控器数字和抽评正文在手机小屏上也能读完。
