# 画面红线：这些东西以后不许出现（2026-10-29）

> 触发：用户看 Day5 片尾卡，圈出 `粉丝 2,108 / 10,000` + 绿色进度条，说
> **「修改下项目，以后这种东西就不要出现了。」**
> 这条是**硬规则**，从 Day5 起所有新片、片尾卡、封面、任何卡片一律适用。

## 一、禁止清单（画面）

| 不许出现 | 为什么 | 换成什么 |
|---|---|---|
| 粉丝数、播放量、点赞数的**具体数字** | 账号体量小，写出来是**自曝其短**；而且数字天天变，片子一过时就变成假数据 | 只写天数、只写「明天干什么」 |
| `X / Y` 形式的**目标值**（如 `2,108 / 10,000`） | 目标写出来＝把自己的 KPI 摊给观众看，观众不关心 | 直接删 |
| **进度条 / 完成度条 / 音量条 / 加载条** | 像后台截图、像工作汇报，破坏「鲸鱼娘在演」的沉浸感 | 什么都不画 |
| 数据曲线、涨跌图、账本表格（含留白待填的表格） | 同上；留白的表格更糟，像没做完 | 不画 |
| 口播里念数字 | 已在 Day5 定过「口播零数字」 | 用「一屋子」「一大堆」这种口语量词 |

## 二、片尾卡取消：**说完话就结束**

用户 2026-10-29 追加：「我的意思是所有都去掉这个就是说完话就结束了。」

→ **一律不做片尾卡**。没有天数卡、没有 `第 N 天 / 30`、没有粉丝数、没有目标值、没有进度条、
没有「明天见」钩子卡。最后一句台词说完，片子就停（只留 0.2s 收尾尾巴，防止把尾音切掉）。

合规口径统一（2026-11-03）：取消的是整张片尾卡，不取消 `agent.md` 要求的常驻小角标。
允许保留右上角 `非官方同人 · AI生成 · 剧情演绎`，它不是片尾卡；发布时仍开启平台AI声明。
禁止新增片尾独立声明画面或延长结尾。本次不修改已交付成片。

## 三、怎么守住（不是靠记性）

```bash
python3 tools/剧本/画面红线体检.py            # 扫所有渲染器，有违规就非 0 退出 + 列行号
python3 tools/剧本/画面红线体检.py --fix-hint # 顺带给出改法
```

体检默认扫描生产 `tools/day*制作/**/*.mjs`（排除测试与历史源码快照）、标准配音TXT及工具目录字幕JSON，`--day N`限定当集，`--file`可点查任意模块/快照，相对路径可用。字幕JSON只扫 `screens[].text`，不把时间戳、哈希等元数据当口播。

- 识别粉丝/目标卡、条形组件、口播阿拉伯数字（包括空格分隔及Unicode数字）。
- 识别显式 `eyes: 'lids'|'dead'`；`squint=0.01`、动态生成眼型仍须代码与近景核验。
- 横向条只对使用progress/barWidth等进度变量的fillRect报嫌疑；不能仅凭矩形长宽比把桌板误杀，也不保证动态计算绘条无漏检。
- `--fix-hint`提供建议，不自动改源码。
- 默认全仓扫描Day1–Day4旧制作目录仅提示，`-v`展开；显式`--file`检查不豁免，重用旧片制作新内容应按新规则检查。

正式制作统一入口：`python3 tools/gate.py --day N --stage final`，配置与检查边界见 `tools/验收/README.md`。静态扫描不等于已看过成片，不宣称无漏防。
