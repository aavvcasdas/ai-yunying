# 剧情生成

先读 `agent.md`。不读不写。

检查命令：`python3 tools/剧本/剧情.py`

细则在 [references/beats.md](references/beats.md)。本文件只留顺序和不能做的事。

## 三拍

1. 开头说找新朋友来帮忙。要帮的是上一集没做完的那件事，不是另起一桌。
2. 只来一个朋友。求职梗写成人话，不丢观众没听过的专名。
3. 梗说完，再接上一集开头没做完的原句，和结尾留在桌上的原句。判断写进嘴里。

## 不能做

- 不改已锁定口播，不重渲，不出 9:16。
- 不用 12/15/18/20/25/201 字退稿。
- 不把同行 skill 的点赞、关注、九比十六、字数配额抄进来。
- 一天不点两位客人。笨鱼不开口。句尾不用呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿。
- 玩梗是戏，不写成新核实的事故。没有出处的评价不编。

## 写完

```bash
python3 tools/剧本/剧情.py --prev Day11/Day11配音台词.txt --card
python3 tools/剧本/剧情.py --prev Day11/Day11配音台词.txt --txt Day12/Day12配音台词.txt --guest 豆包
python3 tools/gate.py --day 12 --stage script
```

失败就看缺的是哪一拍。不要把句子削短来过关。
