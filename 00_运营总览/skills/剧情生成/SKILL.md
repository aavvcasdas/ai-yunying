# 剧情生成

先读 `agent.md`。不读不写。

入口：`python3 tools/剧本/剧情.py`

Day11 及以前的 `tools/剧本/呆萌体检.py` 只给旧集对照。新稿不要为了它改字，也不要再跑那套句长、萌点、201 字预算。

## 写之前

1. 读 `agent.md`，再读上一集锁定口播。不改上一集的字。
2. 跑承接卡，看留在桌上的原句，不要概括成「昨天有张纸」：

```bash
python3 tools/剧本/剧情.py --prev Day11/Day11配音台词.txt --card
```

3. 前两句先点今天这个人。一天一个。梗要写成一句人话，不丢一个观众没听过的专名。
4. 点完这个人，再写别的事：上一集没做完的那一分钟。同一张桌。不另起房间，也不把前几集复述成名单。
5. 判断写进嘴里。不记账，不卖萌，不打人。

## 不设这些门禁

下列数字不再用来退稿，也不再用来把句子切短：

- 12 字首句
- 15 字单句
- 18 字长句比例
- 20 字
- 25 字硬顶
- 60 秒约 201 字
- 前 5 秒必须凑满多少字

字幕一屏十五字是后期换屏，不是写稿理由。句子该多长，看这件事能不能接上，不看字数。

## 仍然要拦的

- 口播数字、过审词、默认自称「本鱼」
- 句尾语气词：呀、啦、吧、嘛、诶、呜、呢、哦、哇、啊、哼、嘿
- 笨鱼开口
- 今天这个人没有出现在前两句
- 一天点进两位客人
- 点完客人之后，对不上一日开头没做完的原句，或对不上结尾留在桌上的原句

## 写完

```bash
python3 tools/剧本/剧情.py --prev Day11/Day11配音台词.txt --txt Day12/Day12配音台词.txt --guest 豆包
python3 tools/gate.py --day 12 --stage script
```

失败时看「可接」后面的原句。补的是承接，不是把句子削到某个字数。
