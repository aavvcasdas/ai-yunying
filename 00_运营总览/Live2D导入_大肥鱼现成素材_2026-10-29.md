## 3. 本次改动：衣服 + 头饰的四套配色

没有重画，只改**布料的色相**——裙 / 胸前的白色围裙不动，蕾丝不动，皮肤、宝石、头发都不动。

| 版本 | 目录 | 裙 & 发箍织带 | 领结 | 侧飘带 / 流苏 |
|---|---|---|---|---|
| 原色 · 藏青 | `out/dafeiyu/original/` | 藏青（未改动，做对照） | 藏青 | 藏青 |
| 深海青 | `out/dafeiyu/teal/` | 深墨绿 + 青绿高光 | 墨绿 | 深绿 |
| 酒红 | `out/dafeiyu/wine/` | 酒红棕 | 酒红 | 暗红 |
| 暮紫 | `out/dafeiyu/lavender/` | 深紫 | 紫 | 深紫 |

### 怎么改的（`src/recolor.mjs`）

直接按 HSL 逐像素做软权重会把**蕾丝边缘染出一圈异色**——这套素材的蕾丝是「带蓝调的近白」，
和布料只差 4~5% 饱和度，阈值一放松就被一起染了。所以改成：

1. **生成布料蒙版**：只认「暗（L < 0.56）+ 蓝调（H 196°~272°）+ 有一定饱和度」的像素
2. **形态学开运算**：`膨胀 → 腐蚀 → 膨胀`，把蕾丝边缘的孤立噪点抹掉
3. **3×3 盒式羽化**：蒙版边缘平滑过渡，不留硬边
4. **只蒙版内换色相**：保留原图明暗，`keepSpread 0.4` 让原色相有一点点浮动，看起来还是手绘的

这样白色围裙、蕾丝、皮肤、宝石、头发**完全没动**，只有布料变。

## 6. 还差最后一步：`.moc3`

`.moc3` 是 Live2D 的私有二进制，只能由 Cubism Editor 或 psd2live 产出；沙箱没有 JDK，这步要在本机跑。

### 路线 A：psd2live（自动，推荐先试）

```bash
git clone https://github.com/tsunehimatoi/psd2live && cd psd2live    # 需要 JDK 21+
./gradlew -p ./psd2live run --args="--input <repo>/tools/live2d/out/dafeiyu/teal/teal.psd --output ./out --atlas 2048 --mesh-spacing 32"
```

自动识别 32 个图层名 → 网格 → 参数 → 导出
`moc3` + `cmo3` + `model3.json` + `physics3.json` + `idle.motion3.json`。
跑完先看 `cmo3`，哪层归错类就在 psd2live 的图层表里改标签，不用回 PS。

### 路线 B：Cubism Editor（手动，能精修）

`Ctrl+O` 导入 PSD → 眼睛四层设 `ParamEyeOpen` 开关（eye close 反转）→ 嘴两层设 `ParamMouthOpenY` →
头发加摆动变形器 + 物理 → 导出 moc3。

FREE 版限制是 1 张 2048 贴图 / 100 ArtMesh / 30 参数 / 50 变形器，**32 层的半身像完全够用**。

### 拿到 moc3 之后

- **VTube Studio**：`.moc3` + `model3.json` + `physics3.json` + 贴图放同一文件夹，拖进模型列表
- **网页 / 直播挂件**：`pixi-live2d-display` 挂透明层，或 `live2d-py`

## 8. 复现

```bash
cd tools/live2d
npm install
node build-pack.mjs                  # 四套配色全出
node build-pack.mjs --only teal      # 只出指定配色
node server.mjs                      # → http://localhost:8080/
```

素材原样在 `tools/live2d/assets/whale-maid/`（94 PNG + rig.json + ATTRIBUTION.md + 上游 LICENSE），
`build-pack.mjs` 只读不改。上游更新时整包替换再重跑即可。
