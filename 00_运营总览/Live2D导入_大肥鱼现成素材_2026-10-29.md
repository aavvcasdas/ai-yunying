## 3. 我做了什么

```bash
cd tools/live2d
npm install
node build-pack.mjs          # assets/whale-maid → out/dafeiyu/
node server.mjs              # → http://localhost:8080/dafeiyu.html
```

`build-pack.mjs` + `src/pack.mjs` 做三件事：

### ① 转分层 PSD

| 项 | 值 |
|---|---|
| 文件 | `out/dafeiyu/dafeiyu.psd` |
| 规格 | **1024×1536 / RGB / 8bit** —— 满足 Cubism 与 psd2live 的硬性要求 |
| 层数 | **32 层**（29 个部件 + 闭眼差分 2 + 张嘴差分 1） |
| 图层名 | 全部落在 psd2live 语义词表里（见下表），**无重名、无蒙版** |
| 校验 | `psd-tools` 读回：尺寸/色彩模式/位深/层数/bbox 全对 |

图层名映射（决定 psd2live 能不能自动绑骨）：

| 原部件 | PSD 图层名 | 语义 |
|---|---|---|
| `backHair` / `longHairLeft` / `longHairRight` | `back hair` / `back hair 2-l` / `back hair 2-r` | BACK_HAIR |
| `neck` / `body` | `neck` / `topwear` | NECK / TOPWEAR |
| `face` | `face` | FACE |
| `blushLeft` / `blushRight` | `facedetail-l` / `facedetail-r` | FACE_DETAIL |
| `chestBow` | `neckwear` | NECKWEAR |
| `eyeWhiteLeft` / `Right` | `eyewhite-l` / `eyewhite-r` | EYEWHITE |
| `irisLeft` / `Right` | `irides-l` / `irides-r` | IRIDES |
| `highlightLeft` / `Right` | `irides-l 2` / `irides-r 2` | IRIDES（数字区分素材） |
| `eyelidLeft` / `Right` | `eyelash-l` / `eyelash-r` | EYELASH |
| `eyelidLeft-closed` / `Right-closed` | `eye close-l` / `eye close-r` | EYE_CLOSE |
| `mouth-N` / `mouth-A` | `mouth close` / `mouth open` | MOUTH_CLOSE / MOUTH_OPEN |
| `headdress` / `ribbonLeft` / `ribbonRight` | `headwear` / `headwear 2-l` / `headwear 2-r` | HEADWEAR |
| `sideHairLeft` / `Right` | `side hair-l` / `side hair-r` | FRONT_HAIR + role `side` |
| `frontHair` / `ahoge` | `front hair` / `front hair 2` | FRONT_HAIR |
| `browLeft` / `Right` | `eyebrow-l` / `eyebrow-r` | EYEBROW |
| `whaleClip` / `tassel` | `objects` / `objects 2` | OBJECTS |

### ② 参数化预览（把「动起来对不对」先验掉）

`out/dafeiyu/sheet.png` 是 2×2 四状态验收图，全部用同一份 `src/pack.mjs` 在 Node 里渲染：

| 状态 | 验的是什么 |
|---|---|
| `idle` | 中立姿态基线：层序、遮挡、有没有露底 |
| `turn + blink` | 转头时五官视差 + 闭眼差分（眼白/虹膜/高光一起收，不会只剩眼白） |
| `talk + body sway` | 张嘴差分 + 身体摆动 + 头发物理跟摆 |
| `half eye + shy` | 半闭眼 + 腮红拉满（`agent.md` 第 11 条的情绪门禁） |

浏览器版 `http://localhost:8080/dafeiyu.html`：7 个参数滑块（转头/抬头/歪头/身体/睁眼/张嘴/腮红）
+ 7 种表情下拉 + 自动眨眼/呼吸/头发物理/说话口型/视线游走，底部实时列 29 个部件。

### ③ 网页清单

`out/dafeiyu/manifest.json` 记录每一层的 PSD 图层名 + 画布矩形，供预览页与后续脚本读取。

## 4. 还差最后一步：`.moc3`

**我没做，也做不了**：`.moc3` 是 Live2D 的私有二进制，只能由 Cubism Editor 或 psd2live 产出；
沙箱里没有 JDK，也没有 Cubism。你在本机跑下面任一条就能拿到：

### 路线 A：psd2live（自动，推荐先试）

```bash
git clone https://github.com/tsunehimatoi/psd2live
cd psd2live
# 需要 JDK 21+
./gradlew -p ./psd2live run --args="--input /path/to/dafeiyu.psd --output ./out --atlas 2048 --mesh-spacing 32"
```

它会自动识别上面那 32 个图层名 → 生成网格 → 建参数 → 导出
`dafeiyu.moc3` + `dafeiyu.cmo3` + `model3.json` + `physics3.json` + `idle.motion3.json`。
贴图用 `--atlas 2048` 就够（1024×1536 的素材，2048 图集不会切太碎）。

> 跑完先看 `cmo3`：如果哪层被识别错了（比如 `irides-l 2` 没归到眼睛），
> 在 psd2live 的图层表里手动改标签即可，不用回 Photoshop。

### 路线 B：Cubism Editor（手动，能精修）

1. `Ctrl+O` 导入 `out/dafeiyu/dafeiyu.psd`，选「维持图层结构」
2. 眼睛四层设 `ParamEyeOpen` 开关（`eye close` 反转）
3. 嘴两层设 `ParamMouthOpenY` 开关
4. 头发做摆动变形器 + 物理演算
5. 导出 → `文件 → 导出运行时 → moc3`

FREE 版限制是 1 张 2048 贴图 / 100 ArtMesh / 30 参数 / 50 变形器。**32 层远低于上限**，
上半身这个体量 FREE 版够用。

### 拿到 moc3 之后

- **VTube Studio**：把 `.moc3` + `model3.json` + `physics3.json` + 贴图放同一个文件夹，拖进模型列表
- **网页/直播挂件**：`pixi-live2d-display` 或 `live2d-py`（Python 侧）
- 想直接接到这个项目现有的直播流程，用 `pixi-live2d-display` 挂一个透明层最省事

## 5. 诚实说明：这版没做到什么

| 做到了 | 没做到 |
|---|---|
| 32 层合规 PSD，图层名按 psd2live 语义，psd-tools 校验通过 | **没有 `.moc3`** —— 私有格式，必须本机跑一次 Cubism / psd2live |
| 用原素材参数化渲染，四状态验收图上能看出视差、眨眼、张嘴、头摆都成立 | 预览是 canvas 2D **近似**，不是 Live2D 的变形器系统；真正的九轴变形要绑骨后才有 |
| 头发物理按 rig.json 的刚度/阻尼模拟 | 没有手臂/腿/尾巴（原包本来就没有这些层，是半身像） |
| 浏览器可实时拖参数、切表情 | 表情只做了 7 种（原包带了 11 种口型 × 6 种眉毛，够扩但要另写映射） |

**一句话**：素材转换和验证这一步做完了，剩下 `moc3` 导出是一个必须在本机跑的步骤。
