# 同类账号调研 · 开头与剧情修复报告（2026-10-27）

> 触发：用户反馈「账号数据越来越差，开头跳出率 50% 左右」，要求 **不改主要赛道、只修内容**，
> 安装 Agent-Reach 去「看」同类型账号，重点看 **开头** 与 **Claude 大小姐等开头**，
> 全面扫 B 站近期、刚起来的号，多关键词多轮，直到找到原因或合适的以后剧情。
> 另：消息里「并参考以下：**我更怀疑哪里出了问题？**」后面的原文/链接没有随消息一起到达，
> 本报告把它当作一个开放问题，在 **第四节** 用「怀疑度排序 + 证据 + 可验证动作」正面回答；
> 若把那份原文贴过来，可以再做一次逐条对表。

**一句话结论：赛道没死，人设和画质也不是主因。真正断掉的是「第一句给陌生人的赌注」。**
头部号靠 **事件 + 连续剧**，新起的号靠 **真金白银的生存赌注**；我们这五条的第一句全是
「内部通知」（大家好 / 先统计 / 复盘 / 正名），而 2 秒跳出率已经约 50%——
冷启动的人在第一句就走了，后面 132 秒做得再好也没人看到。修复只动 **开头 / 结构 / 主线** 三层。

```bash
python3 -m pip install --user --break-system-packages uv     # uv 0.13.6
git clone --depth 1 https://github.com/Panniantong/Agent-Reach.git /home/user/agent-reach-src
uv tool install /home/user/agent-reach-src                    # agent-reach 1.6.0
agent-reach setup                                            # 5/5 默认渠道就绪
```

`agent-reach version` → `{"version":"1.6.0","install_method":"uv"}`；
`setup` 默认渠道：GitHub / YouTube / **B站** / V2EX / 网页，5 项全 ok。

## 三、开头：把他们的第一句和我们的第一句摆在一起

### 3.1 Claude 大小姐 Day0（B 级逐字引用，来自开源复刻长文）

> 83 秒结构：**开场一句「你们人类，胆子还真不小，居然把一整个 B 站账号交给了一个 AI」抛钩子** →
> 角色状态卡（Claude，Lv.0，选题/脚本/视频/运营逐个点亮）→ 今日账本（粉丝 0、播放 0、获赞 0），
> 盖一个章「完美的起点，毕竟不会更低了」→ 问观众想看什么 → Day0 完。
> 长文原话：**「画面是最不重要的那部分」**，火的是「AI 真能自己运营一个号吗」的选题 + 现成社区梗 + 评论区吵真假。

注意：第一句里**没有「大家好」「我是某某」「今天开始更新」**，而是一个对观众的评价 + 一个不可思议的事实。
同一篇文章还记录了复刻者的教训：**「双人号开头先放标题卡，三秒白白浪费」**——等于用真金白银替我们验证了「标题卡＝浪费前 3 秒」。

### 3.2 DeepSeek 鲸鱼娘 Day0 / 媒体口径（B 级）

媒体记录的「开场白」不是台词，是**一句承诺**：
「从今天起，选题、脚本、视频、运营全部由 AI 负责，人类只负责注册账号和审核发布，每天一条视频加一条『今日潜水日志』动态，**数据全部公开**」。
它卖的是**可追看的赌局**（这号能不能活下去），不是「一条视频好不好看」。

### 3.3 ChatGPT 龙娘 Day1（A 级，简介原文）

> 「喂喂，人类。你把账号交给我，怎么把电脑也一起给我了？行，那本小姐可要认真玩了。」

### 3.6 归纳：能过 2 秒的「开头四件套」

1. **对观众说话**（你 / 人类 / 先别划走），不是报幕。
2. **一个具体赌注**：钱（46.36 / 2.56 / 100 元）、权限（连电脑都给我）、身份（被赶出家门 / 有人抢跑）、
   倒计时（还能撑 19 天）、或**真实到刺眼的数字**（9.4 万 → 704）。四选一，越具体越好。
3. **一个陌生人零前情也能懂的异常**：被赶、余额见底、被染成别人、2 秒走一半。
4. **立刻兑现的承诺**：3–8 秒内让观众知道「看下去我会给你看什么结果」（钱怎么花 / 数怎么救 / 谁赢了）。

## 四、我更怀疑哪里出了问题？（按怀疑度从高到低）

### 怀疑 1（最高）：开头不是「不够炸」，是「没有赌注」——这是 50% 跳出的直接来源

- 仓库证据：Day3 前 15.34s 都在做「鱼/鲸正名 + 户口本 + 预告」，事件句在 15.34s；
  Day1 事件在 24.34s；用户最新口径 2 秒跳出约 **50%**（仓库文档记的是 40%+，还在恶化）。
- 平台口径（C 级）：2 秒跳出 <20% 算开头优秀，20–40% 合格，**>50% 必须改前两秒的话术、画面和封面**；
  冷启动池只有几百曝光，前 3 秒留存权重约 40%，不达标就不进下一档。
- 对标证据：3.5 表里每个能起来的新号，第一句都自带一个具体赌注；我们的第一句自带一个「上集回顾」。
- **可验证动作**：下一条片把第一句换成 3.6 的钩子（见第五节钩子库），只改开头，
  对比同一账号下一集的 2 秒跳出率。如果 2 秒跳出不动，再看怀疑 6。

### 怀疑 2：主菜从「连续剧」退化成「日报 / 复盘」，承诺链断了

- 仓库证据：`诊断核对` 已量出——Day0/Day1 结尾都在许下一集（Day1 见 / 把菜名留评论区），
  Day2 起结尾变成结算（票、账本、蛋吃上了）；Day3 结尾「先把蛋吃完，再去吃饭」。
- 对标证据：头部 Day3 用「内部会议」大事件回血到 101.8 万，Day5 用 CP 剧情 31.3 万 / 1192 评论，
  Day7 用「赦免时代」把评论玩成剧情；小号用「余额还剩多少、还能撑几天」串成日记 002/003。
  **他们每集都留了一个未解决的问题。**
- **可验证动作**：以后每集结尾必须留一个「明天我照做什么」的承诺，并由评论区决定；
  复盘内容拆到加更/图文，不做拉新主片。

### 怀疑 3：封面 — 标题 — 第一句三者不同频

- 仓库证据：Day3 封面卖「请不来 Claude，就把本鲸染成了大小姐」，正片第一句却是「鲸鱼不是鱼」，
  染色 15.34s 才出现。封面承诺的事，正片 15 秒后才兑现。
- 对标证据：大肥鱼的b站日记的标题「但已经有人抢跑了」＝它的差异化承诺＝简介第一句；
  小肥鱼在打工的标题「我被赶出家门了」＝简介第一句＝整季前提。
- **可验证动作**：封面只用第一帧；标题只写钩子句，不写「Day N / 更新一下」；集数放简介第二行。

### 怀疑 4：把「画质 / 骨架 / 逐字字幕」当解药，制作资源错配

- 仓库证据：Day2 加更专门回应「画质糊」，播放 3340（五条里倒数第二），
  而同期仓库迭代了高清立绘、10 骨骨架、28 动作、逐字点亮字幕、LIVE 包装——
  制作复杂度一路上升，播放一路下降（9.4 万 → 704）。
- 对标证据：开源复刻长文原话「**画面是最不重要的那部分**」；头部号至今是像素小人 + 卡片 + 打字音；
  415 粉的小号靠一句「余额只剩 2.56 元」拿 5.4 万。
- **推断（不是因果证明）**：画质不是这批观众的流失点。人设、配音、字幕、角色素材全部**不用动**，
  应该把每集 80% 的精力挪到「第一句 + 本集事件 + 结尾承诺」和评论区回复（赛道硬通货）。

### 怀疑 5：赛道回落 + 同质化，把前四条放大了

- 证据：42+ 个同类号、今天新号 20 播放、每小时播放不到高点四成、AI 新稿中位数 119。
  「人类把账号交给 AI」这句话在 10-18 是新闻，在 10-27 是模板。
- 但 2.2 表证明晚入场仍能爆——**前提是换一个新赌注**（被赶出家门 / 只剩 2.56 元 / 有人抢跑）。
- 结论：不是换赛道，是**给同一条赛道换第二季设定**（见第六节）。

### 怀疑 6（不能排除，需要后台数据）：分发 / 人群 / 合规，而不是内容

- 2 秒跳出 50% 也可能是：新视频被推给完全不认识角色的陌生人（而开头假设观众认识她）、
  一天内连发多条互相抢流量、或平台对 AI 内容的分发环境变化。
- 抖音 10-23 起「清朗·整治短视频虚假人设乱象」专项治理，五类违规里包含
  「利用 AI 仿冒人物虚假营销」「编造冲突剧情博取流量」「假扮弱势群体骗取关注」；
  10-01～10-22 已处置 2 万余账号、4.7 万余条视频。**必须继续勾选 AI 生成声明 + 非官方同人标识**。
- **必须补的后台字段**（`诊断核对` 第四节已列，这里按本轮结论重排优先级）：
  ① 留存曲线（2s / 5s / 10s / 30s / 完播）；② 流量来源构成（推荐 / 关注 / 搜索 / 主页）；
  ③ 新增关注 + 主页访问；④ 每条实际发布时间与当天发布条数。
  没有 ① 之前，任何「就是开头」的结论都只是强相关。

## 五、不改赛道的修复方案

### 5.1 锁死不动（用户已定的默认规则，本轮不动）

角色（鲸鱼娘高清立绘 + 大小姐 Q 版）、配音（用户 WAV）、字幕（Day2 加更版，不做逐字点亮）、
账号设定（真人演 AI 运营 / 本鲸 / 评论区是会议室 / 公开账本 / 日更）、非官方同人 + AI 生成标识、
数据不编造、已发布成片不重渲。

### 5.2 只改这六件事

**A. 0–3 秒新规格（覆盖 `开头3秒优化.md` 的五条硬规则，加两条）**

1. 第一帧＝**结果/异常/动作中段**，无淡入、无标题卡、无 Logo、无空舞台。
2. 0–1.5s 必须有人声，且是**对观众说话**的句子（你 / 先别划走 / 人类 / 所有人）。
3. 第一句必须自带**一个具体赌注**：真实数字 / 钱 / 权限 / 倒计时 / 身份异常，四选一。
4. 大字 ≤12 字、两行内、占屏宽 60%+，配描边；**静音刷也能看懂**（抖音静音起播）。
5. 前两句禁止：大家好 / 本鱼回来了 / 先统计 / 复盘 / 上一集 / 更新一下 / Day N。
6. 3–8s 内必须让观众知道「看下去会得到什么结果」——钩子后面立刻跟承诺，不许吊胃口超过 8 秒。
7. **封面＝第一帧**；标题只写钩子句，集数放简介第二行。

**B. 每集 45–70 秒结构模板（一条一个事件，新观众零前情能懂）**

| 时间 | 内容 | 硬要求 |
|---|---|---|
| 0–3s | 钩子：冲突画面 + 大字 + 对人说话的人声 | 自带赌注，静音可读 |
| 3–8s | 承诺：这集要给你看什么结果 | 不许再补前情 |
| 8–35s | 行动：角色**实际做了什么**（不是说了什么） | 用现有动作库，一镜一动作 |
| 35–55s | 结果与代价：一个真数字 / 一次翻车 / 一个反转 | 数据必须有仓库出处 |
| 55–65s | 结算 + **下一个承诺**：「明天我照做你们选的那件事」 | 只留一个动作，不叠加投票 |

**C. 结尾承诺链**：每集必须留一个未解决的问题，且**下一集开头要兑现它**。
复盘/账本/考黑话这类内容降级为「加更 / 图文潜水日志」，不做拉新主片。

**D. 钩子 A/B 不重复发正片**：仓库 `Day3/成片/MV/hook_ab/` 的三条 4 秒样片按 `.gitignore` 不入库，
本轮也没看到它们的投放数据。正确测法是：**接下来 3 集各用一种钩子类型**（数据反差 / 划走指令 / 事件前置），
比较三集的 2 秒跳出率与 5 秒完播率，而不是同一条片换开头反复上传。

**E. 制作资源重分配**：停止为画质/骨架/字幕加码；
每集新增工作量只有「3 个候选第一句 + 1 个真事件 + 1 个结尾承诺」，其余全部复用现有渲染管线。
发布后 60 分钟回前 20 条评论（赛道硬通货是回复率，不是特效）。

**F. 发布/数据侧**：固定 17:30；**一天只发 1 条主片**（GitHub 那个 5 分钟连发 3 条导致 0 播放的复盘是前车之鉴）；
每条记录 2s 跳出 / 5s 完播 / 完播 / 新增关注四个数，形成可比较的台账。

## 六、以后的剧情：三条候选 + 推荐主线

### 候选 A（推荐）：《本鲸的 7 天开头自救》——真数据、真 A/B、真投票

**为什么是它**：不需要新钱、不需要新素材、不需要编任何事实；
把「修开头」这件事本身做成连续剧，天然每集一个新事件 + 一个真结果 + 一个下一集承诺；
而且它就是我们账号的原始卖点——「AI 真的在运营这个号，数据全公开」。

**设定（第 0 秒就能懂）**：本鲸公开自己五天的播放（9.4万→5.3万→5503→3340→704）和
「一半人 2 秒就走」，给自己定 7 天期限：每集换一版开头，第二天公开后台结果，
**下一版用哪句由评论区定**。7 天后如果没救回来，就把这 7 版开头和全部数据做成一张「翻车账本」公开。

### 候选 B（有条件）：《100 元复活预算》——对标「小肥鱼在打工」的生存经济线

如果你愿意**真的**设一笔预算（例如 100 元 / 7 天）并保留凭证：
每天真的花、真的记账、真的公布余额，第一天就超支，剩下六天怎么活由评论决定。

### 候选 C（加更/短打）：《本鲸在营业 · 每天一个脾气》——对标「鲸鱼娘在营业」

30–40 秒一条，不报账、不复盘，只做打工人情绪共鸣：
「被夸一句『还行』，我炸了三小时」「周一早六点半，谁在群里发『收到请回复』？」

### 原 Day4「学抖音黑话」怎么办

`Day4/Day4方案.md` 的 16 镜 / 105 秒版**暂缓作为拉新主片**：
