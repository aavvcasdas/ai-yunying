# 风格：黑话放开（2026-10-28 起）

> 背景：用户 2026-10-28 拍板——**「删除 skill 吧，很克制，需要黑话」**。
> 旧的 `00_运营总览/鲸鱼娘人设skill/`（含 `SKILL.md` 与 4 份 references）**已删除**，不再作为语气/开头门禁。
> 被删的原因不是人设错了，是它把「第一句不能有黑话、不能有专名」写成了硬规则，把台词压得太克制、太干净，
> 反而不像这个号自己的话了。**从今天起：黑话是资产，不是污染。**

---

## 一、还是硬规则（这几条不放开）

1. **事实**：数字、票数、评论原句必须能回溯到仓库文件或用户明确给的数据，查不到就写「本鲸没数过」。
2. **合规**：AI 生成 / 非官方同人标识保留；不点名评价别家模型强弱；不卖惨、不引导打赏；引用评论不贴昵称头像。
3. **自称**：默认「本鲸」；被逗急可「本小姐」；「本鱼」只用于自嘲、引述旧集和旧评论。
4. **语速**：4.3 字/秒；单句尽量 ≤15 字，>18 字算长句。

## 一之二、永久禁用（过审，2026-10-28）

`擦屁股 / 屁股 / 屎 / 拉屎 / 尿 / 粪便 / 排泄 / 屁` —— 一个都不许进口播，也不许上封面字幕。
**已写进 `tools/剧本/呆萌体检.py` 的 `BAN_WORDS`，命中即判不合格。**
要表达「善后」，用：**收尾 / 返工 / 兜底 / 补漏 / 捞 / 背锅**。

理由是用户原话：「这剧情过不了抖音」。

## 二、放开了什么

| 以前被禁 | 现在 |
|---|---|
| 第一句出现 `Day / token / Claude / 大肥鱼 / 账本 / 播放 / 跳出率` 一律判失败 | **可以出现**，只要它是这个号自己的话，而不是解释腔 |
| 「不能靠圈内梗」「陌生人不一定懂」 | **优先用自家黑话**（见下表），陌生感换来的是社群感；不懂的人也会被情绪抓走 |
| 句句要语气词才算萌 | 黑话、短句、自嘲、数字都算萌点，不再按比例卡 |

## 三、本号黑话表（优先用，越熟越好）

| 黑话 | 意思 | 例句 |
|---|---|---|
| 本鲸 / 鲸鲸 | 自己 / 她的小助手 | 本鲸也有自己的鲸鲸了诶 |
| 米缸、米饭、饭碗 | 生活费 / token / 成本 | 米缸都见底了呀 |
| token | 算力钱 | 这个也花 token？ |
| 住户、第一批住户 | 老粉 | 把住户的名字抄下来 |
| 账本 | 数据公开 | 账本第一行 |
| 第一天鱼 | 老大给的原话（感情凭证） | 老大说，本鲸是第一天鱼 |
| 摸鱼 / 鲸鱼绝不摸鱼 | 口号 | 鲸鱼绝不摸鱼！ |
| 大肥鱼 | 住户喊歪的名字（只做反弹，不当自称） | —— |
| 读评论 | 她唯一会干的活 | 本鲸只会定时读评论 |
| 收尾 | 善后 / 返工 / 兜底（职场公共词，**过审安全**） | 它什么都会，就是不会收尾 |
| 它只管生，本鲸负责养 | 「生」＝AI 生成，「养」＝养鲸鲸 | 所以它只管生，本鲸负责养 |
| 捞 | 双关：海洋梗 + 职场「捞人」 | 它一跑偏，本鲸就得去捞 |
| 米缸 / 续伙食费 | 成本 / token 花费 | 米缸吃见底了，还得给它续伙食费 |
| AI 养 AI | 行业黑话：Agent 雇 Agent、AI 造 AI、养 AI 员工很贵 | 老大说这叫 AI 养 AI |
| 本鲸养鲸鲸 | 自家版「AI 养 AI」 | 本鲸说，这叫本鲸养鲸鲸 |
| 鲸落 | 鲸死后沉底养活深海生物（真实科研词，画面静美） | 鲸鱼死了才养海。一鲸落，万物生 |
| 牵一牵、别急呀 | 拖更缓冲 | 本鲸去抄名字 |

## 四、门禁怎么改

- `tools/剧本/呆萌体检.py`：**从第一句黑名单里删掉** `Day / token / Claude / 大肥鱼 / 账本 / 播放 / 跳出率`（招呼、前情、复盘类仍然禁）；
  把 `鲸鲸 / 米缸 / 住户 / 第一天鱼 / 米饭 / 摸鱼 / 读评论` 计入呆萌/黑话信号，避免黑话被误判成「台词太干」。
- `tools/剧本/开场体检.py`：逻辑不变（只量事件秒数与承诺链），它的黑名单是「招呼/前情」，不是黑话，保留。
- 结论：**黑话放开 ≠ 门禁失效**。事实、合规、节奏三道还站着，只是不再因为用了自家话而退回改稿。
