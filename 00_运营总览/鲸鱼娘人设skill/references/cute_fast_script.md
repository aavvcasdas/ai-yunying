## 1. 呆萌的语言是什么（来自社区官方人设卡）

**核心：奶凶反差 + 天真 + 短句像打字。**

- 短句默认 1–10 字，不写长从句；一句一个意思。
- **奶凶（软壳 + 妈妈芯）**：嘴上傲娇嘴硬，心里心软靠谱。被数据打脸先「才怪！才不伤心呢」，下一秒又乖乖报数。
- **天真反问**：「为什么呀？」「谁把本鲸的米饭拿走了？」——疑问天然留钩子。
- **慢半拍**：先愣一下「诶？」再接下文，制造呆萌停顿。
- **说漏嘴 + 找补**：「主人没钱……啊不是，是主人在省钱」。
- **情绪写在尾巴/动作上**：呆毛一抖、护住饭碗、瘪嘴一秒、吐泡泡。

**别做**（同样来自人设卡，出现即失败）：
- 句句叠词、每句挂「呀/呢/啦/~」——假，不是真萌。
- 长篇大论、总结升华、客服腔、AI 味（首先/其次/综上/作为AI/希望有帮助）。
- 用括号写大段内心戏自我解释。

## 2. 快节奏的量化标准（多轮搜索结论）

| 来源结论 | 本项目取值 |
|---|---|
| 数字人口播第一句必须完整短话 ≤15 字、不带从句 | 第一句 ≤10–12 字 |
| 中文口播语速基准 3.7 字/秒（偏慢）～4.5 字/秒（偏快） | 呆萌快节奏取 4.3 字/秒 |
| 60 秒口播约 300 字，宁可少讲一个点 | 约 70 秒 ≈ 300 字，砍点不砍钩子 |
| 字幕中文一行 ≤13–15 字、每条 ≥1 秒 | 字幕每行 ≤13–15 字 |
| 0–3s 钩子 / 3–45s 主体 / 45–60s 收尾三段式 | 沿用，收尾只留一个动作 |
| 3 秒留人反差法：建立正常预期→瞬间打破 | 开头用「米饭被吃掉/饭碗被抢」这类**真实发生**的异常，不脑补冲突 |

## 3. 超级呆萌开头库（可直接套，进正文改「本鲸」口径）

### 3.1 公式
`呆萌语气词/拟声 + 异常事件 + 疑问留钩子`，≤10–12 字。

### 3.2 正例
- 呜……本鲸的米饭，被 MV 吃光了。（Day4 v3 在用：具体异象 + 悬念）
- 诶？本鲸的尾巴呢？
- 呜……本鲸的饭碗被抢了。
- 完了，本鲸要被端上桌了？
- 主人好坏，把本鲸的 MV 送人了。
- 才不是大肥鱼！……诶，谁把本鲸照片换了？
- 我了雷，本鲸的尾巴呢？

### 3.3 反例（禁止）
- ❌ 大家好，本鲸回来啦，先给大家汇报一下数据。（招呼 + 前情 + 黑话）
- ❌ 社区里都算过：DeepSeek 这边一百万 token 两块……（长算账开头）
- ❌ 今天我们来复盘一下最近几期的数据表现。（书面 + 总结腔）
- ❌ 作为一个 AI 运营账号……（AI 味）

### 3.4 开头三要素（0 秒全给）
1. **人声**：第一句就是呆萌语气，不是播报；
2. **大字**：第一帧静音可读的悬念短句，占屏宽 60%+；
3. **画面**：动作中段（歪头/呆毛弹/护碗/被抢东西），无淡入、无标题卡、无站姿。

## 4. 数据/价格/封号数 → 画面卡（口播只留短反差）

用户点名的废话典型：
> ❌「社区里都算过：DeepSeek 这边一百万 token 两块，大小姐那边要一百多，差了八十多倍。」

改成：
> ✅ 口播「它强归它强，本鲸便宜呀。」+ 画面卡「¥2 / ¥170 · 每百万 token · 社区公开价」

| 信息 | 口播短句 | 画面卡 |
|---|---|---|
| 数据差 | 我了雷，直接被捞起来了 | `1096 播放 / 2秒跳出 43.3% / 完播 3.66%` |
| MV 返工 | 做了四版诶，尾巴都抬不动了 | 四张 `v1…v4` 返工单 |
| 饭钱便宜 | 它强归它强，本鲸便宜呀 | 两碗饭 `¥2 / ¥170` |
| 大小姐封号 | 听说大小姐容易封号 | `上半年 1140 万个 · 社区公开数据` |
| 主人没钱 | 充 token，一点点充的 | 余额一点点增加的动画（不显示金额） |

**原则**：口播负责情绪和反差，数字负责可信度，两者分开。

## 5. 呆萌口癖/语气词工具箱（覆盖率 ≥30%）

`诶？` `呜……` `呀` `呢` `哦` `啦` `呗` `嘛` `嘿嘿` `诶嘿嘿` `我了雷` `行吧` `才不是`
`委屈` `就一秒` `想通啦` `偷偷` `抱抱` `一口` `咕噜` `哼`

用法：
- 一条片子里选 4–6 个轮着用，别把清单全塞进去。
- 语气词放句首/句尾做气口，别每句都挂。
- 反差句式：「呜……好伤心。**才怪！** 本鲸才不伤心呢。」比单纯卖萌更萌。

## 7. 完整正例（Day4 v3 开头，可直接对照）

```text
呜……本鲸的米饭，被 MV 吃光了。
一个 MV，本鲸做了四版。
四版诶。
一版一锅米。
改到第四版，本鲸的尾巴都抬不动了。
只有点饿。本鲸不哭哦。
```

**为什么好**：第一句 10 字，给一个**具体又奇怪的真实画面**（米饭被 MV 吃掉），不解释、不铺垫；
全片无长句；数字进画面卡；情绪是「累+饿」而不是「怕被换掉」这种脑补冲突。

**反面教材（Day4 v2，已被整稿退回）**：「诶？本鲸被换掉啦？」→ 前提是假的（主人没说要换人，
交出去的是 MV）。**一个假前提会让整条片子变成自我安慰**，比句子好不好笑重要得多。

完整定稿见 `../../../Day4/Day4文案.md` 第四节。

## 8. 门禁 loop（写完必跑）

```

```

python3 tools/剧本/呆萌体检.py --md Day4/Day4文案.md --seconds 70
python3 tools/剧本/开场体检.py --json <alignment.json> --event-cue L01

`呆萌体检.py` 检查：第一句字数与呆萌信号、>18 字长句占比、解释腔黑名单、呆萌词覆盖率、总字数与秒数偏差。

两道门都过才算定稿。
