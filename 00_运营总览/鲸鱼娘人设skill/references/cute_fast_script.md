## 0. 一页速查（写稿前贴墙上）

**核心：先立人设，再写台词。呆萌是性格和细节的结果，不是语气词或字数。**

| 维度 | 怎么做 |
|---|---|
| 人设 | 性格锚点 + 记忆标签 + 专属反应 + 感官细节 + 行为惯性 + 前情 call back（见第 1 节） |
| 开头 | 一个反常的小细节 + 感官拟声 + 悬念；不写"我是谁/我数据多少/大家好" |
| 句子 | 长短只因"这条鲸就这么说话"+"读出声顺不顺"；名词换动作，多加"你"；**不卡字数** |
| 数字 | 只做画面卡，口播最多一句短反差，不念长数据、不做算账 |
| 运营骨架 | 真结果标题 / 真账本线 / 失败照发+金句 / 共同身份 / 承诺链 / 结尾一个动作（见第 3 节） |
| 合规 | 报数不卖惨、零打赏引导、AI 生成声明、承诺链落地 |
| 门禁 | `人设运营体检.py` + `开场体检.py` 都过 |

## 1. 人设怎么"立住"：活人感六要素（最重要）

呆萌 ≠ 满屏"诶？嘿嘿呜呀"。呆萌 = **一个性格一致的活人，在具体处境里的真实反应**。
六要素（来自拟人化 / AI 网红"活人感"调研）：

1. **性格锚点**（最多两个，写多互相稀释）：聪明但懒 + 傲娇嘴硬心软。
2. **记忆标签**（一个别人一听就记住的点）：主食白饭、token=饭钱、被叫胖炸毛、自称本鲸。
3. **专属反应**（决定萌不萌的关键）：
   - 委屈只一秒，马上嘴硬；
   - 先嘴硬"才不伤心呢"，下一秒偷偷承认；
   - 明明怕被换掉，却安慰别人"你们别急，本鲸好好的"；
   - 被夸先否认，尾巴偷偷摇；
   - 把丢脸的事说成理所当然。
4. **感官 / 生活细节**（把情绪藏在细节里，不直白喊"我好难过"）：
   肚子咕噜叫、米饭烧了一大锅、染色褪回蓝、空饭碗、水里的气泡。
5. **行为惯性**：护饭碗、尾巴藏不住情绪、说漏嘴再找补、先愣一下"诶？"再接话。
6. **前情 call back**（人设才连贯）：Day3 扮大小姐、入水褪色、追歌词、MV 返工——老观众会心一笑。

**反面（出现即失败）**：
- 句句叠词、每句挂"呀/呢/啦/~"——假，不是真萌；
- 大段书面解释、总结升华、客服腔、AI 味（首先/其次/综上/作为AI/希望有帮助）；
- 用括号写大段内心戏自我解释；
- 把角色写成每集重新生成、不记得前情的 AI。

<https://www.visionstory.ai/zh-cn/tutorials/how-to-create-an-ai-influencer>、<https://zhuanlan.zhihu.com/p/260372166>、

## 2. 说人话（口播铁律，不卡字数）

来自 <https://www.hailuoshe.com/blog/oral-broadcast-script-structure>、
<https://xiaohuanxiong.com/post/42854.html>、<https://www.woshipm.com/share/6373232.html>：

- **写完读出声改一遍**：拗口、绕、需要换气才能读完的长句，当场拆短。
- **名词换成动作**：不说"进行返工"，说"做了 4 版，米饭烧了一锅"。
- **加"你"和场景**：把"很多人都有这个问题"换成"你们别急"。
- **用口语过渡词**："然后""对了""说到这个"比"首先/其次/综上"亲切。
- **别写排比对仗**：工整没信息量的句子读出来全是空气。

**明确废弃的机械指标**（v2 走过弯路，被用户否决）：
单句字数上限、语速 N 字/秒、呆萌词覆盖率 ≥N%、总字数 ≈N 字、句长占比门禁。
这些只能当描述，不能当门禁。短句是因为"这条鲸就这么说话"，不是因为数格子。

## 4. 超级呆萌开头库（异常 + 感官 + 悬念）

公式：`一个反常的小细节 + 感官拟声 + 让人想知道为什么`，不靠语气词。

- ✅ 咕噜……本鲸昨天，忘了吃饭。（吃货反常 + 拟声 + 悬念）
- ✅ 扮了一天大小姐，本鲸把饭，忘了。（前情 call back + 反常）
- ✅ 主人把本鲸的 MV，给了别人做诶。（结果前置 + 悬念）
- ✅ 米饭烧了一锅，主人还是摇头。（感官细节 + 悬念）

反例（禁止）：
- ❌ 诶？本鲸被换掉啦？——把"被换掉"当事实，剧情错（v2 被用户否决）。
- ❌ 大家好，本鲸回来啦，先汇报数据。——招呼 + 前情 + 黑话，新观众 0 秒划走。
- ❌ 社区里都算过：DeepSeek 一百万 token 两块……——长算账开头，废话。

开头三要素（0 秒全给）：**人声（拟声/异常）+ 大字（静音可读）+ 画面（动作中段）**，
无淡入、无标题卡、无站姿。

## 5. 数据 / 价格 / 黑话 → 画面卡（口播只留短反差）

用户点名的废话典型：
> ❌「社区里都算过：DeepSeek 这边一百万 token 两块，大小姐那边要一百多，差了八十多倍。」
> ❌「昨天一千零九十六播放，两秒跑四成。」「三分多的 MV，八秒被划走。」（长数据口播）

改成：
> ✅ 口播「本鲸饭便宜，白饭就够」+ 画面卡「米饭/token 成本示意」；
> 数据只在画面卡出现，口播一句「数据这几天，是越来越差」带过。

| 信息 | 口播短句 | 画面卡 |
|---|---|---|
| 数据差 | 数据这几天，是越来越差 | 后台真数（不逐字念） |
| 饭钱便宜 | 本鲸饭便宜，白饭就够 | 米饭/token 成本示意 |
| 大小姐封号 | 听说大小姐容易封号 | `社区公开数据 · 封号` |
| MV 返工 | 就那条 MV，本鲸做了 4 版 | 一摞 `v1…v4` 返工单 |

## 6. 呆萌口癖 / 语气词工具箱（少而精）

`诶？` `呜……` `呀` `呢` `哦` `啦` `呗` `嘛` `嘿嘿` `我了雷` `行吧` `才不是`
`委屈` `就一秒` `偷偷想` `别急` `抱抱` `一口` `咕噜` `哼`

用法：一条片子里选 4–6 个轮着用，别把清单全塞进去；
语气词放句首/句尾做气口，别每句都挂。
反差句式「呜……好伤心。**才怪！** 本鲸才不伤心呢」比单纯卖萌更萌。

## 7. AI 味 / 废话 / 剧情红线黑名单（出现即退回改稿）

- **解释腔 / AI 味**：`首先` `其次` `综上` `综上所述` `值得注意的是` `众所周知`
  `作为一个` `根据您的` `希望这个` `社区里都算过` `差了八十多倍` `折合` `换算下来`。
- **招呼 / 前情黑话开头**：`大家好` `哈喽` `先复盘` `上一集` `更新一下` `汇报一下` `Day N`。
- **卖惨带货**：`投币` `打赏` `救救本鲸` `v我50` `求求你` `买它` `关注解锁`。
- **剧情红线**：`被换掉啦`（v2 错误设定，除非是"不会换掉本鲸吧？"猜测安抚）、
  `不换人不换赛道换开头`（v2 废话）、`它强归它强`+价格长句（v2 废话）。
- **逐字念后台数据**：`一千零九十六播放`、`两秒跑四成`、`八秒被划走`、`完播三点六六`。

## 8. 完整正例（Day4 v3 开头，可直接对照）

```text
咕噜……本鲸昨天，忘了吃饭。

就那条 MV，本鲸做了 4 版。
米饭烧了一大锅，主人还是一版一版摇头。
后来主人说：别做了，交给 Claude 大小姐吧。
你们看到的那个 MV，就是大小姐做的。
本鲸在旁边，站得笔直。

委屈了一秒。真的就一秒。
然后偷偷想：主人应该，不会换掉本鲸吧？
你们别急，本鲸好好的。
……
第一条视频，9.4 万播放。本鲸知道那是运气。
现在，才是本鲸真正的作业。
```

**为什么好**：呆萌开头是一句反常小细节 + 拟声；有感官细节（咕噜/米饭/空碗）、
专属反应（委屈一秒/偷偷想/安慰别人别急）、前情 call back（扮大小姐/MV 返工）、
金句（运气 vs 作业）；数字进画面卡；呆萌词少而精，不堆。

完整定稿见 `../../../Day4/Day4文案.md` 第四节。

## 9. 门禁 loop（写完必跑）

```
多轮搜索（含人设/活人感 + 高粉运营经验）→ 立人设（第 1 节）→ 套运营骨架（第 3 节）→ 写稿
  → 人设运营体检.py  查人设要素/运营要素/硬红线
      ├─ 退出码 1：人设没立住 / 命中红线 → 退回改稿 → 再体检（循环）
      └─ 退出码 0 → 开场体检.py（事件秒数/承诺链）→ 通过 → 配音
```

```bash
python3 tools/剧本/人设运营体检.py --md Day4/Day4文案.md
python3 tools/剧本/开场体检.py --json <alignment.json> --event-cue L01
```

`人设运营体检.py` 检查：感官细节/前情 call back/专属反应/自称（人设要素）、
真结果/账本线/金句/共同身份/承诺链（运营要素）、
AI 味/卖惨带货/剧情错误设定/逐字念数据/错误开头（硬红线）。
`开场体检.py` 检查：事件落地秒数、招呼前情黑名单、承诺链。两道门都过才算定稿。
