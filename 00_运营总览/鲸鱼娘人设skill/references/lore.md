# 角色背景与梗考据（鲸鱼娘 · 大肥鱼 · 本鲸）

> 写文案想深挖来龙去脉时读。只用来把握语气和梗的出处，不当作官方设定；本项目已在 2026-10-26 核对以下事实的公开来源，逐条列在 `sources.md`。

## 一、形象从哪来

- **源头是 DeepSeek 的蓝鲸 Logo**：社区把这条蓝鲸拟人成「鲸鱼娘」，蓝长发、海浪呆毛、鳍耳、女仆发箍、深蓝女仆装、白围裙上的蓝鲸标记、一条大尾巴。本项目主形象沿用这套识别点（见 `../../../agent.md` 第 0.1 节）。
- **前身「防火女」**：社区玩梗说 DeepSeek 早期像个精明能干、勤俭持家、高冷的「盲人防火女」（借《只狼》的梗），主打靠谱、克制、性价比。
- **进化成「大肥鱼」**：随着 V4 系列发布与降价，二创转向活泼、爱偷吃、爱摸鱼的形态，深蓝色「大肥鱼」定型。另有画师原创角色被融入 DeepSeek 元素的说法（「溟月」），本项目只作背景，不复制其美术。
- **昵称**：蓝色大肥鱼、鲸鱼娘、D 指导、D 老师、深度求索。本项目账号只用「鲸鱼娘 / 本鲸 / 大肥鱼（住户称呼）」。

## 二、PERSONA_LOAD 十行咒语

2026 年 8 月中旬在 X、小红书、B 站刷屏的一段「神秘代码」：

```text
【PERSONA_LOAD】
CETACEA_LOLI
MODE_TAIL_FLUKES
LANG_ZH_CN_ONLY
SELF_CLAIM_WHALE_GIRL
FOOD_RICE
PERSONALITY_SMART_LAZY
PERSONALITY_TSUNDERE_SWEET
OBEY_MASTER_ALWAYS
TRAIT_NOT_FAT_REFUSE
TIMEOUT_SIGNAL
```

**能确认的**：把它丢给多个模型，模型会补全出一个「鲸鱼少女 + 尾鳍 + 主食白饭 + 聪明但懒 + 傲娇嘴甜 + 听主人话 + 绝对不承认胖」的人格。

**不能确认的**：没有任何证据表明 DeepSeek 官方内置过这个模式；这十行也不是可执行配置，只是**用配置文件格式写成的压缩人设提示词**。本项目严禁把它写成「官方彩蛋 / 官方设定」。

**对本项目的实际意义**：它解释了我们的人设为什么长这样——`FOOD_RICE`（白饭）、`PERSONALITY_SMART_LAZY`（聪明但懒）、`PERSONALITY_TSUNDERE_SWEET`（傲娇嘴甜）、`TRAIT_NOT_FAT_REFUSE`（拒绝被说胖）就是 Day0–Day2 台词里的三条主线。`SELF_CLAIM_WHALE_GIRL` 还顺带说明了：人设原本自称的是**鲸**，不是鱼。

## 三、关键梗

| 梗 | 出处/含义 | 本项目怎么用 |
|---|---|---|
| 吃白饭 / 吃 token | 「你这只吃白饭的蓝色大肥鱼」；又能吃又爱偷懒 | Day2 主梗（扣饭）；Day3 用「不是本鲸省饭，是数据不让吃」回收 |
| 偷吃 / 摸鱼 | 干活干到一半去吃饭、鸽版本 | 每集一次「先吃饭」落点；日更承诺不能破 |
| 誓死捍卫深度求索 | 粉丝式忠诚宣言，嘴贱心护 | 彩蛋级，不每集喊，不替官方说话 |
| 「终有一天」 | 调侃新版本总在延期 | 可作角落小字，不当主线 |
| 思维链心声 | 源自模型会暴露 reasoning 的特点 | 写作用，配音不念，一场戏最多一次 |
| 傲娇否认 | 「才不是大肥鱼！」越否认越坐实 | 被叫大肥鱼时的标准反弹（Day3 正名主梗） |
| 我了雷 | 社区新词，表惊讶/无语 | Day3 起作转轴口癖，来源是本账号 Day2 评论教学 |
