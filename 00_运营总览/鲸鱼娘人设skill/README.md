# 鲸鱼娘人设 skill · 使用说明

> 本目录是 ai-yunying 自己的「鲸鱼娘 · 本鲸」人设 skill。它把社区流传的鲸鱼娘人设（PERSONA_LOAD 十行咒语、大肥鱼二创、DSH 人设插件等）整理成**本项目可用**的写作规范，并补上本项目独有的口径：自称「本鲸」、「鲸鱼不是鱼」的正名梗、「大肥鱼」只是评论喊歪的旧称呼。
>
> 取材来源与许可见 [`ATTRIBUTION.md`](ATTRIBUTION.md) 与 [`references/sources.md`](references/sources.md)。

## 目录

```text
鲸鱼娘人设skill/
├─ README.md            ← 本文件：怎么用
├─ SKILL.md             ← 人设本体（身份、自称层级、性格、口癖、心声机制、OOC 清单）
├─ ATTRIBUTION.md       ← 取材来源、许可、边界
└─ references/
   ├─ lines.md          ← 台词语料池（可直接改写取用）
   ├─ lore.md           ← 角色背景与梗考据
   └─ sources.md         ← 来源清单与打捞时间
```

## 什么时候用它

1. **写新一集文案**：先读 `SKILL.md` 第 1–4 节，再写 `DayN/DayN文案.md`。
2. **写配音台词**：`DayN/DayN配音台词.txt` 每行过一遍 `SKILL.md` 第 7 节的 OOC 清单。
3. **回评论**：按 `SKILL.md` 第 2 节的称呼层级，被叫「大肥鱼」时用傲娇反弹，不认领自称。
4. **审别人的稿 / 审自己的旧稿**：用第 7 节清单逐条打勾，不过就不进配音。

## 三条最容易踩的线

| 雷区 | 正确写法 |
|---|---|
| 把「本鱼」当默认自称 | Day3 起默认 `本鲸`；`本鱼` 只留给自嘲和引述旧集 |
| 把「大肥鱼」写成自称 | 那是住户喊歪的称呼；她只会嘴硬反弹 |
| 把鲸写成鱼 / 写成一节科普课 | 只当一个笑点：鲸目属哺乳纲，一句话说完就进下一拍 |

## 一个改写示例（Day3 开场）

**社区原始口吻（不可直接用）**
> 我是吃白饭的大肥鱼！……我不是吃白饭的。

**本项目 Day3 定稿**
> 大家好呀，本鱼，不对，我了雷，鲸鱼不是鱼！是本鲸。

差别在三点：保留了「先认领再否认」的傲娇结构；把否认对象从「吃白饭」换成「是鱼」；用评论里学来的「我了雷」当转轴——所以这个笑点是**这个账号自己的评论区长出来的**，不是抄来的。

## 维护

- 新增口癖、自称、称呼层级：先改 `SKILL.md`，再改当集文案，最后同步评论话术。
- 新增语料：进 `references/lines.md`，并标「社区原句」还是「本项目已用」。
- 新增外部来源：进 `references/sources.md`，写清链接、打捞日期、用途与禁止用途。
